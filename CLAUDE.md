# 2D == nz=1, no separate code

There is NO 2D code path. `nz == 1` IS the exact 2D restriction: periodic wrap maps k±1 -> k, every z-stencil term cancels identically (same address minus itself), w stays exactly 0. Kernels, cut-cell operators, CG, reductions: all shared, untouched.
Only the solvers special-case degenerate axes:
- Periodic: `hipfftPlan2d` when nz==1; lamz={0} (poisson.hip).
- NeumannBox: degenerate axis has no ghost ring (m=1), DCT pass skipped — rotation across a size-1 axis is a memory no-op; pack/unpack ghost offset 0 there (`ghostOff`).
- `closeBoxBoundary`: leaves degenerate-axis faces open/periodic.
Constraints: only z may be degenerate (nx,ny > 1); NeumannBox needs n>=4 per confined axis. Use hz=1 (unit depth).
When touching kernels/solvers: keep the cancellation exact (never branch z-terms out), and keep tests `*2d` (parity 2D vs z-invariant 3D slices) green.

# DNS vs LES — which runs mean what

The core scheme is DNS: KE-conserving skew-symmetric advection, the ONLY dissipation is the physical ν. Valid iff the grid resolves the smallest active scale (body BL ~ D/√Re). Refining the grid converges to the answer. Cylinder 512², D=64 cells: honest up to Re≈500 (BL≈3 cells). Beyond that the separated shear layer piles enstrophy at the grid scale and the run blows up (~t=3 at Re 3e5) — no CFL/tol setting fixes zero dissipation.

`cylinder_tunnel_gpu --les Cs` (2D only, default 0=off) switches to LES: adds per-stage div(νt grad u), νt=(Cs·Δ)²|S|, Δ²=hx·hy (app-local kSmagNut/kEddyDiffuse; shared kernels untouched). Consequences — never blur these:
- LES output is a FILTERED field; statistics depend on grid AND Cs by construction (measured pre-ghostfill: cd 1.70±0.34 @512² vs 1.88±0.44 @1024², νt ∝ Δ²). Not a discretization error; do not present LES numbers as converged predictions.
- Dissipation at the body is model-supplied; cd/St/separation carry model error. `cdf` friction column uses ν only (no νt in the surface stress).
- 2D caveat: Smagorinsky models a 3D forward ENERGY cascade; 2D cascades energy up and enstrophy down (no vortex stretching), so 2D+--les = stabilized/regularized 2D Euler, qualitative only.
Rule: if the run needed --les to survive, label it LES everywhere (reports, artifacts, memory) and state Cs; DNS label only when --les 0 and BL ≥ ~3 cells.
