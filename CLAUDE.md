## Ground rules

- ONE solver binary: `build/dns <flow|tgv|hit|channel|conv|flame|bench|prop>`. `dns --help` / `dns <sub> --help` are authoritative — read them, don't guess flags.
- `dns-ui` (scene editor, run cockpit, live viewer) links `dns_core` ONLY — never `dns_gpu`, never a solver. It RUNS a case by spawning `dns` and WATCHES it by mapping the run's shared-memory segment. `docs/ui.md`.
- Live results are shared memory: `--emit shm` (`src/dns/shmframes.hpp`) publishes planes, mask, 3D volumes under a SEQLOCK (writer bumps odd, copies, bumps even; reader copies between two equal even reads, discards a torn one). The solver NEVER blocks on a viewer. Volumes capped at 512 MB, else planes only.
- `--dry-run` validates + prints the resolved case (and DNS/LES label), no GPU or filesystem. Use it before every real run.
- Parsing is strict: unknown/missing/non-numeric flag = hard error. Exit codes: 0 ok, 1 CLI, 2 config, 3 input, 4 output, 5 no GPU, 6 resource, 7 numerical, 8 non-convergence, 77 skipped.
- `main` = Parse → Validate → Acquire → Run. Phases 1-2 touch neither filesystem nor GPU; phase 3 creates every output before the first `hipMalloc`.
- `std::expected` for anything a USER can cause; `assert` only for what a PROGRAMMER can cause (only if the validator makes it unreachable). Release is the build that runs — never assert-as-input-guard.
- Build: `build/`, CMake+ninja, **Release always** (never RelWithDebInfo — disk space), one GPU backend ON. ctest; GPU tests skip (rc 77) without a device. Always run tests with a timeout.
- TWO GPU backends, ONE set of sources: `src/dns/gpu/*.hip` is HIP; `DNS_WITH_CUDA=ON` compiles the SAME files through the shim `src/compat/cuda` (read its README). Never fork a solver per backend; never `#if DNS_WITH_CUDA` outside the shim — a HIP call the shim lacks is a build error ON PURPOSE: extend the shim in the same commit. App code uses `DNS_WITH_GPU` (not `DNS_WITH_HIP`). Backend name (`gpu::backendName`, `backend=` provenance) = `DNS_GPU_BACKEND_NAME` from the CMake backend branch, not a header `#if`.
- GPU arch AUTO-DETECTED (`CMAKE_HIP_ARCHITECTURES` / `CMAKE_CUDA_ARCHITECTURES`); wrong HIP arch = `getStatFunc` assertion. CUDA needs nvcc `-std=c++23` (configure compiles `<expected>`); CMake ≥ 4.3 needs the CUDA23 dialect flag taught, which the CUDA branch does.
- Long runs: `run_in_background`, act on the completion notification. No Monitor/sleep/until polling.
- **Every GPU run and every heavy CPU run (OpenFOAM, GPU ctest) goes through the job server**: `build/simjob submit (--gpu|--cpu) -t SEC -m MB --wait -- EXE ARGS` (multi-step / OpenFOAM: `--spec FILE.json --inherit-env`; timing measurements: `--bench`). Caps 1800 s / 16384 MB. One gpu + one cpu job at a time. Never run the GPU outside it. `docs/jobs.md`.
- Artifacts when asked to publish: dark mode; videos colormapped with curl and |velocity|.

## Layering

`cli/config` (pure parse+validate; also `dns/scene`, `dns/remap`, `dns/sgs`, `dns/rans`) → `bodies/geometry` (sdf + cut sampling; also `dns/curvmesh`, `dns/framemap`, `dns/walldist`, FP64 oracle `dns/rans_channel1d`, implicit host line `dns/channel_line` + `dns/blockband` + `dns/pseudo_time` — header is constants/declarations only, so config may read its cap) → `gpu/{tunnel,bodyforce,les,rans,cutpoisson,cutflux,derived,comp_channel,comp_conv}` → `gpu/runner_{incomp,comp,channel,conv}` → `output` (RunOutput, the one artefact sink). Preserve it; validated physics constants live at their definitions with the measured bracket.

## Invariants you must not break

- **2D is `nz == 1`, not a code path.** Periodic wrap cancels every z-stencil term; w stays exactly 0. Never branch z-terms out. Only solvers special-case degenerate axes (hipfftPlan2d, DCT skip, open box faces). Only z may be degenerate; `hz = 1` validator-enforced. Keep `*2d` parity tests green.
- **Ghost view is diffusion-only.** `gpu/ghostfill.*` mirror values never reach convection or the state (measured energy injection). Ghost faces have zero aperture.
- **Tunnel lateral walls are free-slip/Neumann.** No Dirichlet `u=uInf` far field (paints a wall vortex sheet).
- **Open/lateral BCs leave normal velocity free.** Relaxing v→0 or u→uInf laterally is a wall in disguise. Open tunnel: laterals slaved once per stage BEFORE projection; post-projection refresh is `refreshOnly=true` (re-slaving broke div u ~150×).
- **The compressible RK stage is FUSED: no materialized rhs.** `kCompStage`/`kCompStageCurv` write `out = ca*a + cb*b + cr*(-div F)` in one pass (`StageCombine`, `gpu/comp.hpp`): two stage buffers. (1) Stage output never aliases `cmb.a` — a boundary rhs hook is a second kernel re-reading `a`; stage 3 writes `q1_` and swaps. (2) Buffers swap, so no caller holds a raw device pointer into the state across a step.
- **NSCBC is an RHS overwrite** (`setRhsHook`), never a state overwrite. Inflow relax stays stiff (`--nscbc-etain`, default 100) WHEN THERE IS A FREESTREAM TO SAG. With none (static rotor) it is an acoustic mirror (0.81 back on a normal wave); there etaIn is worth 280×, the transverse coefficient 3% — don't reach for the transverse term first. Outflow needs the Yoo-Im transverse term (`--nscbc-beta`, default 0.5; 1.0 diverges).
- **`--nscbc-beta` is a constant; the right coefficient is not**: `beta_opt = cos t/(1 + cos t)` at incidence t (measured optimum 0.2 at 75 deg). `--nscbc-abc adaptive|modal` reads t off the face (`Tp/Lout = (1 - cos t)/cos t`) and is EXACT at every angle (Engquist-Majda symbol summed, no time history); normal incidence bit-for-bit. `adaptive`: per face cell, every open face, any mesh. `modal`: per DCT-II mode of the x-hi plane, exact eigenbasis only with free-slip lateral walls; rejected (never ignored) with `--open`, `--stretch`, `--focal`, `--ogrid`, `--body floor`. At 75 deg vs best constant: adaptive +34%, modal +1.0% (a pointwise ratio reads an AVERAGE angle). `docs/nscbc.md`, `gpu_nscbc_order`.
- **Measuring a boundary**: NON-WRAPPING difference (a whole-grid scan differences outflow against inflow across the periodic wrap; peeling cells also peels off a boundary-made sheet). State where the peak sits; show the number flat in time. An oblique reflection's measurement window closes in a square box past ~45 deg.
- **What the face cannot absorb is the sink's** (`gpu_comp_sink`, docs/nscbc.md). Central flux transports nothing at the mesh scale (group velocity `c cos(kh)` ≤ 0 below 4 cells/wavelength): 98% of a kh = pi packet strands; a 4dx vortical patch PARKS. `--nscbc-sink N` (+ `--nscbc-sink-amp`, (0,2] = SSP-RK3 bound): D4/sin^4 selective damping, conservative flux form, banded inside open faces, additive rhs UNDER the NSCBC overwrite. Zero on constant and linear fields — no freestream reference, so it cannot sag, wall, or eat the near field (resolved vortex: sink keeps 0.9999, strip 16 0.6813). Does NOT fix the resolved inflow mirror — that is etaIn's or the strip's. **ON BY DEFAULT (16, amp 1) for `--far nscbc` wherever defined** (uniform mesh, whole faces, band fits twice per open axis; Re60 cd +0.003%). `--nscbc-sink 0` = bare boundary bit-for-bit. The default stays off on `--stretch`/`--focal`/`--ogrid`/`--body floor`; an EXPLICIT sink there is rejected. The ONE exception to "no absorbing band by default" (no freestream reference) — it does not justify a sponge.
- **The lateral relax writes vorticity ∝ its rate** (`gpu_nscbc_order`): `etaLat c/L (v_t - tgt)` is the source, 0.20/0.80/2.16 of incident scale at etaLat 0.05/0.25/1.0 (free-slip walls 0.22). Plain `--open` = sink 16 + etaLat 0.05: residual 0.032, 7× below walls; open Re60 cd -0.003%. The walls' 0.22 is resolved vorticity parked in a quiescent box — only a freestream advects it out.
- **The inflow acoustic mirror is the sag guard's own** (`gpu_nscbc_absorb`). `--nscbc-etain-shear` rates the lambda = u family (L2, L3/L4) separately (default: follow etaIn, bit-identical); softening it 400× moves R_inflow 0.1% — a normal wave reflects off the `u = uInf` clamp itself, so only `--nscbc-etain` or the strip fixes the mirror. The family rate owns vorticity written under vortical load (0.0069 → 0.0050 at 100 → 0.25); its customer is turbulent inflow (L3/L4 at 100 clamp every eddy).
- **Sponge is NEVER a default — anywhere, any physics, any mode.** `--far sponge` (eats the near field) only when the user names it. Compressible default is `--far nscbc`. Struct/runner defaults stay off sponge.
- **`--far nscbc` alone only to Re800**; beyond, `--nscbc-sink 16` (preferred) or `--nscbc-strip ~ny/64` — validator enforces one.
- `--pot` off, or Q=0 ∧ a=0, is bit-identical (test-pinned). `csLes == 0` is bit-for-bit molecular DNS.
- Deterministic iteration/order wherever output depends on it.
- **Threaded host sweeps are bit-identical to serial** (`dns/parallel.hpp`: `CurvMetrics::build`, `sampleCut`, `compressibleBodyIC`, `classifyCompGhost` on the MRF and `--thin-seal` paths; `host_threads` byte-compares 1/2/3/7/hw/over-count). Rows as contiguous blocks (`forBlocks`) or an atomic queue (`forItems`), each cell its serial expression, writes to its own index only, one sdf copy per worker; a reduction keeps one partial per `forBlocks` block merged in block order and only if exact (min/max); a validator error is the lowest block's first. Never an FP sum across threads.
- **The editor covers `dns flow` and `dns conv`, both physics of each.** `DocState::sub` picks the subcommand; panels gate wholesale on it. Conv's SI face: height + temperature drop + material → Ra DERIVED (as size + freestream → Re). `dns-ui --check` has a COMMAND ROUND-TRIP GATE: exported argv → real `cli::parse` + `validate` must reproduce the document's case at the printed 4-significant-digit precision.
- The self-check owns `/dev/shm/dns_uicheck*`, clears them at BOTH ends, asserts nothing outlived it (a leak fails the NEXT `--check`). A stop before a run reaches its time loop is still not clean — `docs/ui.md`.
- **The editor owns no physics.** It CALLS `dns::sceneObjectBox`, `sceneBoxInside`, `needs3d`, `validSceneName`, `defaultSceneName`, `checkSceneNames` (`dns/scene.*`; `parseScene`/`buildSceneGeometry` route through them). Never restate a rule in `src/ui/` — move it, refactor the core caller onto it in the same commit. The editor's scene IS `parseScene(sceneToml())`.

## Temperature (compressible)

- Air, **calorically perfect**, gamma = 1.4 FIXED (gamma(T) deliberately not modelled). `dns/transport.hpp` (`dns::Transport`) is the ONE gas object and the only route for mu, kappa — `Comp::tr`, `DeviceComp::transport()`, `gpu::viscView()`. No scalar mu/kappa pair.
- Every thermal knob OFF by default; naming none is bit-for-bit the pre-thermal solver (keeps cd/cl anchors). `--visc sutherland`, `--tinf K` (the ONLY dimensional anchor; Sutherland's 110.4 K is not scale-free; box T scale 1/(gamma M^2)), `--prandtl`, `--wall adiabatic|isothermal` + `--twall RATIO` (body), `--nscbc-tinflow`.
- Sutherland ONCE PER FACE on the face-average T (the Fourier flux's average) — exactly conservative. Never per cell.
- **Diffusive dt limit is thermal**: `0.25 h^2 rho_min / (mu_max * max(1, gamma/Pr))` (energy carries `gamma nu / Pr`, 1.94× nu for air). With Sutherland, `mu_max = mu(max T)` from ONE reduction — valid because the law is monotone.
- Wall heat flux rides the cd/cl tally (`qw`, positive = fluid into body); it is CONDUCTION, so adiabatic = exactly zero.
- `--temp` adds a third frame channel (`temp` = T - Tinf) to compressible flow and O-grid runners; off by default (a thermal knob must not silently change artefacts). `conv` always emits it.

## Gravity and buoyancy (`dns conv`)

- **Gravity exists only in `gpu/comp_conv.hpp` `addGravity`** (axis 1 = conv's y, axis 0 = the candle's x): `m += cr*(-g rho)`, `E += cr*(-g m)` via `setRhsHook`, riding SSP-RK3; the fused stage kernel is untouched. Conv's axis-1 arithmetic is the old `addGravityY` bit for bit. Other subcommands (and every flame mode but candle) run at g = 0, bit-for-bit. No second buoyancy term.
- **No Boussinesq approximation in the compressible solver**: buoyancy IS rho(T) g through the EOS.
- **The IC is hydrostatic**: `convIC` integrates `dp/dy = -rho g` through the conduction profile (`p = pRef (T/Tref)^(-g/(R a))`); uniform start rings the box all run. `conv_config` pins 1e-4.
- **Two temperature scales — do not "unify".** Only the SUPERADIABATIC excess `dTsuper = dtemp - (g/cp) H` drives convection; `--rayleigh` is on `dTsuper` (critical ~1708); Nusselt is on the FULL drop (conduction = Nu 1). Subadiabatic = config error, rejected by name.
- **`--mach` sets gravity** (`g = M^2 gamma / dtemp`); adiabatic fraction `M^2 (gamma-1)/dtemp^2` (10% default, 1.6% at 0.02). Lower M = closer to Boussinesq, more steps per free-fall time.
- `gpu_conv` (2D Pr 0.72 coarse, NOT converged): Ra 1000 → Nu 1.00; 2e4 → 3.00; 5e4 → 3.81. Wall vs interior Nu < 5% IS the heat balance; a spread means a bug.
- **`conv` has two physics = two MODELS.** `--physics compressible` (default): `gpu/comp_conv` + `runner_conv`. `--physics incompressible`: `gpu/boussinesq` + `runner_rb`, free-fall scaling (H = dT = g*alpha = 1, nu = sqrt(Pr/Ra), kappa = 1/sqrt(Ra Pr)). `--mach`, `--dtemp`, `--visc sutherland`, `--tinf` are REJECTED there, never ignored.
- **Cross-validation is the load-bearing test**: branches share case derivation and output sink, NO physics. Ra 5e4 2D: compressible 3.79, Boussinesq 3.97 (`gpu_rb`, band 15%). Touch buoyancy, a wall or T transport → this tells you which branch broke.
- **`--sides closed` is a different experiment** (sealed cavity): x, and z when nz > 1, become no-slip **ADIABATIC** walls on the plates' one-cell ghost ring (`kRbWallSide`, `kConvWallSide`, indexed by `internal::sideGhostPair`, order y→x→z so a corner ghost is the diagonal reflection). Two extra cells per closed axis; fluid extent, spacing, `--n`/`--nz` unchanged (`nxInterior`/`nzInterior`; `sideGhostX/Z` in `gpu/index.hpp` is the ONE offset, read by kernels AND host plane divisors). Adiabatic because the PLATE drop is the experiment: a side copies T and p, antimirrors momentum. Boussinesq pressure → `PoissonBc::NeumannBox`. Periodic is bit-for-bit flagless on all four paths; the IC trip envelope is branched per axis. Ra 5e4 aspect 2 closed Nu is BELOW periodic (2D Bouss 3.65, comp 3.38, 3D 3.58) — a cavity number, no 1708, no Ra-Nu scaling. Subcritical closed stays at rest (Nu 1.00: wall fill forces nothing); heat balance closing = sides leak nothing. Both gpu tests carry a 3D cavity: a wrong-axis z plan leaves every 2D case green.
- `PoissonBc::PeriodicXZWallY` (`gpu/poisson.hip`): FFT x/z + exact TRIDIAGONAL y, NOT a mixed DCT. `hipfftPlanMany` IGNORES istride/idist when inembed is null and silently transforms the wrong axis. `gpu_poisson_wally`.
- **The Boussinesq IC MUST break up-down symmetry** (`rbIC`'s `cos(pi y/H)`): the equations are equivariant under (y → H-y, T → -T, v → -v) and a symmetric trip locks the run (wall Nu equal to six digits — unfalsifiable). `gpu_rb` pins time means equal AND instantaneous values different. Compressible needs no term (stratification).
- **`--hot-patch F` heats a centred FLOOR fraction** (surround at lid T). `F = 1` byte-identical (`gpu_rb`). 3D: side fraction, area F^2; nz == 1: middle x strip. Below 1 it is NOT classical RB (`nuBot` is a net floor flux; validator warns). Wall-gradient Nu pins the AREA-MEAN wall T (`hotPatchAreaFraction`, in cells), not Tbot.
- The progress line in `runner_{channel,conv,rb,comp,ogrid}` has its OWN counter (`lastPrint`); sharing `lastLog` made it unreachable. Both live in `internal::StatsCadence` (`gpu/internal/run_loop.hpp`).
- Boussinesq diagnostics are interior-only: ghost rows carry divergence ~0.5 vs interior 3e-6, so `maxDiv` zeroes ghosts first (`zeroGhostCells`).
- Domain y walls in `gpu/comp_far.hip` are hardcoded ADIABATIC mirrors (`E[c] = E[s]`). Only `DeviceConvWall` and `DeviceChannelWall` carry wall T; `--wall`/`--twall` on `flow` is the BODY, never the box.

## Rotors — moving geometry (`dns flow --rotor-mach`)

- **`--rotor-mach` is the ONE switch; 0 is bit-for-bit static** (keeps cd/cl anchors). Other rotor flags rejected without it. Compressible `flow` only.
- **The moving wall is the isothermal wall's image**: `u_ghost = (1+a) u_wall - a u_sample`, `a = gscale = dw/dsmp` (`gpu/comp_ghost.hip` `kGhostFill`). Resting branch VERBATIM under `if (uw)` — `a*a*(ui*ui)` ≠ `(a*ui)*(a*ui)` in float. Without the term a blade is a rotating HOLE.
- **`comp_ghost` owns no motion model**: a `GhostWallMotion` callable returns `GhostWallKinematics{u, a}`, sampled once per ghost at the FOOT OF THE WALL NORMAL (`a` feeds the pressure image). Rotor: `gpu::rotorWallMotion` (`dns::rotorWallVelocity` + `dns::rotorWallAcceleration`). Never put `omega` in that module.
- **Azimuth is COMPUTED, never accumulated**: `theta = omega * t`, bin = integer mod bins — so a revolution closes exactly.
- **Geometry is fixed within a STEP, not a stage** (tip moves ~0.1 fine cell per acoustic step). Do not "fix" this.
- **A swap moves momentum no tally sees** (`gpu_rotor_swap_ledger`, `plans/verify/impl_mrfmove.md`). The tally's convective fc is NOT a body force; the swap ledger is its counterpart and `ct_c + ct_sw` (moving-only columns) is the swept wall's NET sink — a discretization error. A freed cell enters on the wall profile (`SwapLedgerScratch::reseedCreated`: ghost image reflected about u_w), never on its image (the wall-relative velocity REVERSED: moving vs MRF CT −69%; wall profile +5.6%). Quote a moving rotor on `ct` with the sink stated; `ct - ct_c` = force on the body.
- **The azimuth table is HOST memory replayed into ONE device buffer set** (`gpu/rotortable.*`, threaded; `classifyCompGhost` pure host, reentrant). `DeviceCompGhost::fromTables` sizes for the largest bin; `load()` is a copy, never an allocation, and REFUSES a table past capacity.
- **`--blade-thicken` CHANGES THE BODY; report it like the DNS/LES label.** `sdf - C*h_fine` = Minkowski sum with a ball (true distance). Needed because the ghost wall wants >= 2 mirror cells per side (`gpu/comp_ghost.hpp`). `casegeom` applies it via `rotorSdf` at theta 0 (the ONE definition) so ghost wall and `qRef` see one body; the runner turns with `thicken = 0`.
- **Resolution gate is MEASURED**: deep-solid cell count over all bins, warn at 0.
- **`--rotor-mach` is on the NOMINAL tip `D/2`**; the runner measures the real tip from classified interface faces and STOPS with the corrected number (`--body lens --aspect 4 --rotor-mach 0.4` = tip Mach 1.61).
- **Rotors are exempt from the `--focal` mesh-body rejection**: the swept volume is bounded by `--dr` and `--rotor-span` (≤ 0.5). `rotorSweptBox` = flags-only (validator); `rotorSweepBounds` = measured (run).
- Torque rides the SAME staged FP64 face values as drag (`kBodyMoment`: spans 0..2 of `facc_` → 4..6). Face positions travel in the tables (`fpos`): on focal they are the REMAP of the reference face, which `CurvView` lacks.
- **The moving mask reaches only sinks that re-read it**: `RunOutput::updateMask` (frame time, toggling two bins' solid lists) refreshes PNG frames and shm planes. `<prefix>_mask.bin` and the web `static` mask hold azimuth 0; making them time-dependent is a viewer-format version bump (`docs/viewer-format.md`).
- **`--rotor-frame mrf` is the frozen-rotor APPROXIMATION and says so everywhere.** Static azimuth-0 geometry, same `u = ω×r` image, rotating-frame equations (transport `u − f·ω×r`, Coriolis `−fρω×u`, pressure work on absolute u) in a blended cylinder sized off the swept bounds, REJECTED within (band + 4) cells of a face. (1) Transport correction is a CORNER STREAM POTENTIAL difference (`ψ = −ω f_a G(r)`, `G' = r f_r`), so it telescopes — never the pointwise `f·ω×r` (3e-2 velocity ring). (2) The tally passes the same `MrfView` as the rhs. (3) `stableDt` subtracts the frame velocity (eigenvalues `u_rel ± c`). Exact only for axisymmetric outer conditions (`gpu_mrf`: spinning cylinder vs direct 1e-4); warn for crossflow. `--rotor-bins` rejected; `rotor.bins == 1` and `Case::rotorMrf` is the switch. **O-grid MRF** (`--ogrid --rotor-frame mrf`, z shaft; moving geometry rejected): `DeviceComp::setMrfCurv` uses a per-NODE stream potential (face flux = Δψ of two corner nodes, telescopes on any z-extruded mesh, cancels the wall's normal flux at f = 1); wall row mirrors about `ω×r` at face midpoints (resting verbatim at ω = 0); tally adds the shaft moment. `gpu_mrf`: vs Cartesian direct 0.22%, transparency 6e-8.
- **`--rotor-frame mrf --steady` = pseudo-time on the frozen rotor, immersed + `--focal` + laminar only, and NOT a speed-up** (measured 2026-10-28, `plans/verify/impl_M1.md`). Stop: ct, cq (observables) + ∫(ρu_a − ρ∞U_a)dV (monitor). `--steady-sample N` (cadence) and `--lts-max R` (ratio cap) absent = the old march byte for byte. Fixed point lts-independent (rotor2 L1 ct 0.037694 at R = 1/2/4/∞; `gpu_mrf_steady_lts`: random lts 0.81× the lts ≡ 1 drift, applyRhs on the bare cr 107×), but LTS slows it monotonically (ct inside 1% after 8100/19600/23850/25550 iterations at R = 1/2/4/∞ vs the 8570-step time march); nothing certifies at M 0.08–0.11 within 60000 iterations. `--far sponge` / `--nscbc-strip` rejected with it: a per-stage state relaxation's fixed point moves with the lts ratios.
- **`--precond K` = Weiss–Smith low-Mach preconditioning of the explicit laminar `--steady` march** (`dns/precond.hpp`, `DeviceComp::stepPrecond`, `plans/verify/impl_M2.md`). Rank-one correction `R' = R − ((1−ε)/c²) a bᵀR` on the TOTAL residual (`residualInto`: stage kernel + every rhs hook) — never on the stage kernel's part alone (fixed point P R_k + R_h = 0 is wrong). Hooks see a pure-residual combination; lts multiplies the corrected R in `kPrecondCombine`, so the G7 trap is unreachable there. ε = 1 on every overwrite row (`!fluid` + the box's outer layer: NSCBC assumes physical eigenvalues). `localDt` takes the ε of the SAME `PrecondCell` evaluation (`kLocalDtPrecond`). Absent = `step()`/`kLocalDt` byte for byte (G1). RANS rejected (point-implicit scalars). Measured: rotor2 L1 K 2 settles ct to 1e-3 in 15500 it vs 59900 (∞) / 29700 (R=1), +20% per iteration; K 1 DIVERGES there (U_r floor below the tip-speed scale); O-grid cylinder M 0.1 needs MORE iterations (diffusive-bound wall), M 0.05 fewer but no wall win.
- Not built: on-disk table cache, incompressible branch, `dns-ui` support (editor `Build` is one `geo.cut`: azimuth 0 only).

## Chemistry (`dns flame`, `docs/chem.md`)

- **Species off is the solver bit for bit.** `nY == 0` takes no new branch in any kernel and `StageCombine` is unchanged (species ride `SpeciesCombine`). HEAD-vs-branch stats byte compares (flow comp + NSCBC + sink + ghost, conv, channel 3D, channel RANS) and the bench enforce it.
- **Species ride the central MASS flux of `faceFlux` verbatim** (`Real(0.5)(ρa+ρb) * Real(0.5)(ua+ub)`), MC-limited MUSCL face value. Measured host: van Leer p = 1.75, upwind −2% at 15 cells; MC 2.12. A power-of-two uniform Y is exact to the bit through every stage, hook and band (`gpu_flame_passive`).
- **One ω buffer per stage, read by both the species rhs and the heat release** (fused in the species launch, before the rhs hook).
- **The rate floors Y; the state is never clamped; the guard counts** (`yHits`).
- **Order inside the rhs hook: NSCBC → species re-carry → sink → species sink.** The re-carry must see the NSCBC density before the sink writes ρ. The species sink adds Y × the band's continuity term — D4 on ρY itself is unbounded on Y (measured 1 + 2e-5), do not bring it back.
- **Mach inflation** is allowed for the non-dimensional model and is in the label (`flameRunLabel`). M 0.01 is the sweet spot: M 0.005 is FP32-contaminated (issues.md §31).
- **S_L is measured on a SLIDING flame** (`--inflow-speed 0.98`, window [10, 20]): a stationary flame near |S_h − u_in| ≲ 1e-3 pins to the grid (issues.md §30).
- **`--mode bunsen` (2D slot) anchors on a BURNT PILOT, measured**: burnt coflow (default) or ≥ 3 δ_th burnt strips at the jet speed hold; cold/T 3 coflow, a cold u = 0 rim, slow thin strips blow off at U_jet 5 (docs/chem.md). Don't "anchor" it on the inflow face. The exit-8 guard counts only BURNING Tmid crossings (a hot pilot crosses Tmid without a flame).
- **Per-row inflow is its own kernel instantiation** (`kNscbcCells<…, Prof>`, `kSpeciesStage<Row>`): empty = the shipped kernels; a uniform profile through them is bit for bit (`gpu_flame_passive` (f)). Never branch at runtime in those kernels.
- **The bunsen hook re-adds `crAt q ω` on the open rows after the NSCBC overwrite** (`speciesBoundaryHeat`: it burns there); the 1D hook does not (bits); the diffusion jet does NOT (an open tip in the outflow LODI row ran away to 4.3 T_ad, issues.md §48).

## DNS vs LES vs RANS labeling

Only dissipation is physical ν; DNS iff the grid resolves the body BL (~D/√Re). `--les Cs` FILTERS — statistics depend on grid AND Cs, `cdf` uses ν only. If a run needed `--les` to survive, label it LES everywhere (reports, artifacts, memory) with Cs AND model (`--sgs smag|sigma`). σ-model (Cσ ≈ 1.35, NOT a Smagorinsky Cs; `dns/sgs.hpp`): zero in laminar shear / any 2D state, transition-capable; rejected at nz == 1. 2D + `--les` = regularized 2D Euler, qualitative only.
LES nut takes the RANS wall image (`setMutHook`: odd at walls, even on mirror rows); tallies carry SGS (`gpu_les_wall`, `gpu_les_tally3d`).

A RANS field (`dns channel --rans`, `docs/rans.md`) is an ensemble-mean MODEL output, never a grounder. Label `RANS SA-neg` / `RANS SST-2003m` / `RANS SST-Vm` plus mode (`steady (local time stepping: pseudo-time, not time-accurate)`, `steady (implicit Newton pseudo-time: not time-accurate)`, or `URANS (time-accurate)`) everywhere. Invariants:
- **RANS off, and ν̃ ≡ 0 / k ≡ 0, is DNS bit for bit** (`gpu_rans` G1/G2). μt rides the LES `nut` slot; the ONE hot-kernel edit is `cmb.cr` → `cmb.crAt(c)`. `faceFlux`/`faceFluxCurv`/`kPrim`/`wall_ghost.hpp` untouched.
- **μt is ODD across wall ghost rows** (`kMutMirrorY`) → 0.0 on the wall face; never from ghost scalars. Ghost scalars mirror the SPECIFIC value with the ghost's density; SST ω images TMR's 60ν/(β1 d1²).
- **Every `cmb.cr` consumer uses `crAt(c)`**; additive hooks take the whole `StageCombine` (bare cr under LTS converges to lts·R + f = 0, G7).
- **Residual = explicit-mode extra stage** (ca = cb = 0, cr = 1, hooks in, scalar kernel in residual mode), never state differencing.
- **SA-neg is TMR SA-neg WITH ft2.** ν̃ never clipped; SST's k/ω guard is COUNTED (`floorHits`).
- **Scalars convect first-order upwind on the mean mass flux** — verbatim `faceFluxCurv` expression (G3: 0 ulp). Mean flow gets NO added dissipation; a stall is a user decision (U1).
- **Per-cell diffusive dt is RANS-only**; DNS/LES `stableDt` byte-identical (its LES bound is over-conservative on clustered meshes — recorded, not fixed).
- **FP32 steady residual cannot certify convergence**: it stalls at |R|·dt ≈ ulp(q)/2 (resid ~1 vs 0.04 at the oracle state) while ub is still 1.6% off; the solution does reach the oracle (`gpu_rans` G9 plain, G10 compensated). Pin against `rans_channel1d`, not a residual.
- **`--steady TOL` stops on INTEGRALS** (`dns/steady_stop`): ub, bulk T, ∫ρν̃ | ∫ρk, ∫ρω each within TOL of a geometric extrapolation over the history's second half, every window row monotone to 2^-20. Keep SEVERAL series (ub alone stopped 2.8% low) and the monotone check (a damped oscillation stopped 8.7× early). Monitor bulk T, not T − Tw (noise 5e-6 vs 3e-8). `gpu_runners`.
- **`--steady` marches a COMPENSATED state** (`DeviceCompState::lo`, Kahan low word; kernels read hi). Every stage write (any new StageCombine consumer too) goes through `gpu/internal/stage_write.hpp` (`stagePut`/`stageAdd`, a + cb(b − a) + cr R, exact as ca == 1 − cb). Plain vs compensated is a COMPILE-TIME switch (`withCompensation`) — a runtime branch moved NSCBC bits via FMA contraction. A new state OVERWRITER on a compensated state zeroes its cells' low words (the channel wall does). Fixed point 2000× tighter, still ~10× above the static floor — hence the integral stop. `--compensated` applies it to a time march (plain FP32 URANS diverges as dt → 0; docs/rans.md).
- **`--steady-scheme implicit`: rhs = GPU residual-mode stage; `dns/channel_line` only preconditions** — its R never reaches an update (`gpu_rans_implicit` I1/I2). Explicit stays default, byte-identical.
- **One column, broadcast**: host FP64 column, device FP32 copy in every column. Exact only because the RANS channel mean is x/z-homogeneous (homogeneous IC, `--kick` rejected) — never generalize. ρw stays 0.
- **Total mass is pinned by projection to the IC mass** (the steady equations are a one-parameter family in mass; LTS drifts it, −7.8e-4).
- **Line Jacobian is CENTRAL FD in FP64, K = 1 SA / K = 2 SST.** Forward FD stalled Newton on SST Re_τ 1e4 (centreline, v = 0 kink); SST K = 1 has a 0.70/iteration tail or diverges at CFL ≥ 300.
- **Never build J by FP32 FD of the GPU residual** (step window non-monotone, case-dependent).
- **The stop listens only after an undamped step AT the CFL cap** (else it certified a damped stall 1.1% off). 27–28 iterations, ≤ 8e-8 off the oracle, Re_τ 180 to 1e4.
- **O-grid far boundary is its own characteristic row**: `--nscbc-*` and `--pot` rejected with `--ogrid`; Re > 800 only warns.
- **`dns flow --steady` stops on a JITTER FLOOR (`steadyFloor`); the channel keeps `steadyRemaining` bit for bit.** External integrals jitter white at the FP32 floor (pressure coefficients amplify p's ulp by 2/(γM²)). Trend from block means vs a noise limit; cd/cdf certify on trend + √2·jitter < TOL; monitors also need jitter ≤ 2^-10 (`kSteadyJitterMax`). Per-series trend/jitter line always printed. TOL below the jitter never certifies — by design.
- **The wedge has TWO azimuthal widths**: ρ (`aov`) for the time march, ρΔφ (`aovSteadyZ`) for the steady local dt only, with a RELATIVE collapse guard (1e-3 × first dtRef; axis dtRef ~7e-7). Widening the time-march width caused a pseudo-time limit cycle.
- **Axisymmetry = mesh + ghost hook**: axis faces S == 0 with the analytic limit metric; ghost columns carry R_x(π) continuation on their real neighbour's metrics.
- **Immersed RANS scalars**: ghost k image EVEN and quadratic (a²·Σw·k; odd fed negative k into corners); interface faces convect ν̃, k at wall value 0; open-face scalars re-carried by mean-flow density after the NSCBC hook (`rans::openScalarConsistency`); μt ghost clamped so μ + μt ≥ μ on every staircase face (`μt_g = −min(a Σw μt_s, fluid face neighbours' μt)`; odd image hit −39 μ, `gpu_rans_immersed` (e)). Label `[immersed ghost wall: first-order wall position, NOT body-fitted]`.
- **Flow NK**: R always the GPU residual-mode stage, dissipation only in P; lexicographic line-GS only (red-black stalled at 200 Krylov); FD step 2^-14. In NK kernels stage operands with unrolled loads first — a load-wait-use loop serializes (59 → 13.4 ms).
- **OpenFOAM parity**: v2606 SA defaults ft2 OFF, Prt 1.0 — set `ft2 true`, Prt 0.9. `exactDistance` fails in parallel: run serial. **A parity number names OpenFOAM's U scheme**; reference is central `linear` (`tools/parity/sph1e4.py`) — linearUpwind moved SST cd 2.8–7.6%, L_r 14–28%.
- **SST-2003m Re 1e4 wedge limit cycle is the model's own unsteadiness** (URANS: cd 0.404–0.424). Don't "fix" it in the explicit march; report the URANS time mean, labelled URANS. SST audit found no model difference (`sstRestatement`, `gpu_sst`).
- **A front sawtooth in a steady LTS march = no steady wake**, not a front bug (LTS concentrates wake radiation in fine front cells). Coarse-wedge exit 8 accepted; only dissipation cures it.
- **Full revolution (`--ogrid --body sphere --nz N`, N even ≥ 4)**: axis ghost columns VERBATIM copy (i_s, j, (k+N/2) mod N), Cartesian components unrotated. aov[2] = 1/(ρΔφ); `aovSteadyZ` empty.
- **Full revolution is exactly π-symmetric**: odd azimuthal modes NEVER arise from rounding, so an untripped run certifies an unstable symmetric state. `--ogrid-trip A` seeds m=1 (laminar Re 250: cd 0.710, cl −0.065; Johnson & Patel ≈ 0.70 / 0.062).
- **The full revolution trips by DEFAULT** (`kOgridTripDefault` 0.05 U, bracket in `ogrid.hpp`). `--ogrid-trip` valid on every O-grid except the axisymmetric wedge; default 0 elsewhere (bit for bit untripped, as is `--ogrid-trip 0`). `--kick` REJECTED with `--ogrid`. Trip always in the label. The steady stop carries `cd+cl` and `cd+cs` — cd is EVEN in m=1 and stays flat while the mode grows. Never drop them.
- **`--init-from PREFIX` revolves a converged wedge** (`revolveWedgeState`), checked by meridional nodes, closure, Mach: mismatch = exit 3, never a silent re-grid. An untripped wedge start is not evidence of 3D stability.
- **Full-revolution DNS dt is a TRUE axis limit** (axis cells' azimuthal width; stable 2×, diverges 3×). Only implicit azimuthal diffusion on the axis ring or coarser axis cells remove it.
- **3D equals the wedge** at Δφ = 2π/N to the jitter floor (cd 4e-5); second order in Δφ; polygonal body is the discretization, qRef stays the circle's.
- **URANS turbulence scalars are first order in time** (point-implicit stage quotient; `gpu_sst` (a)). Steady fixed points unaffected.

## Known gotchas

- **`offsetsAt` (gpu/index.hpp) has `gidx`'s contract**: one cell out of range MUST wrap. Sparse boundary/surface kernels ask for `j-1` at `j == 0`; offsets from `j == -1` disagree at the wrap (silent 0.4 freestream drift at NSCBC corners).
- `dns bench` honours `--physics` and reports VRAM THIS process allocates.
- Upstream "ripples" near bodies are 6-12h dispersive standing waves forced by the SUB-CELL BL — not staircase noise, not a start transient. `--cut-flux` ~20% (incomp only), `--penalize` ~15% (HALVES cdf), `--ramp` ~0%. Only cure: resolve the BL (D/√Re ≥ 3 cells). No filters/limiters.
- **Anisotropic cells break isotropy assumptions.** The ghost wall's deep-solid threshold is a DEPTH following the WIDEST local spacing, else drag inverts (`--focal` aspect 1.7: cd 1.49 → −7.6). Audit any `min(hx,hy,hz)` used as "the" cell size before a clustered mesh.
- **`--focal` plateaus are PHYSICAL**: `Focal1D`'s a, b, w are REFERENCE coordinates — build with `Focal1D::fromPhysical`. Containment, guard (3 h_fine), BL warning are physical; `test_focal` pins spacing = h_fine over body + guard. qRef never passes through the map (`sampleCut`, uniform world lattice). Fine cells cost R× their width out of `--n`; adjacent growth > 1.25 rejected.
- **Ghost-wall tally closed by construction** (`gpu_comp_ghost_closure`): a solid cell in any fluid cell's flux stencil (face + edge) is ALWAYS a ghost; with an unusable normal image (overlapping mesh parts) it is imaged from its fluid neighbours — never reset to rest (that opens the tallied surface).
- **Incompressible ghost image reads a CLEAN trilinear cell** (`gpu_tally_couette_torque`, `gpu_ghostfill`): renormalizing over open corners is O(h) off (Couette friction plateaued +6-12%). The image steps out along the normal (1/16 cell, up to a diagonal) until clean; q_ghost = (sdf/d) q(image). Imposed friction is first order (wall curvature); no quadratic image (weights ~7, unbounded ghost). Unresolved spots take a capped fallback (`fallbackCount()`, 0 on resolved convex bodies).
- **Compressible ghost `a` follows the sample it ACTUALLY reads** (`gpu_comp_ghost_couette_exact`): `normalImage`'s renormalized sample sits at sum(w phi)/sum(w), not dsmp; dropped-corner ghosts use that, full stencils keep dw/dsmp bit-for-bit. Any wall-linear profile is exact.
- **Compressible ghost-wall faces are IMPERMEABLE** (`DeviceCompGhost::applyRhs`, `gpu_comp_ghost_imperm`, `plans/verify/impl_imperm.md`). The KG face mean of a cell and its odd image does not zero u_n: the body was a placement-dependent mass source 0.1-1.1% rho U c. Fluid/ghost faces advect nothing relative to the wall: rest — no advection, no pressure work; MRF — none relative to the frame, pressure work p w_n off the SAME corner stream potential; moving — rho u_wall.n {1, u, e} + p u_wall.n, u_wall at the FACE CENTRE (`CompGhostTables::fuwall`). Pressure, viscous and conduction fluxes kept. One thread per fluid cell (CSR from `fcell`), stageAdd/crAt, no atomics; side faces end on the side image's impermeable flux. The tally uses the same override (fc EXACTLY 0 at rest and under MRF). **Anything stepping a `DeviceComp` with a ghost wall puts `applyRhs` in its rhs hook.**
- **`--thin-seal` seals the staircase's leaks, not the body** (`classifyCompGhost` thinSeal, `gpu_thin_seal`, `thin_seal`, `plans/verify/impl_propperf.md`). A fluid/fluid face whose centre segment crosses the body (sphere trace from both ends, midpoint strictly inside; never across the wrap) is an interface face of BOTH fluid cells, each with a side image about its own surface (`addSeal`, the two-sided builder): kernels need no change (`kWallRhs` makes it impermeable, `kSideRhs`/`kSideTally` read each side's image). Mask, ghosts, deep, gfnb unchanged; 0 sealed faces = bit-identical; flag off = byte-identical tables. The sdf must be a distance (lower bound). Not on RANS scalars, the moving-rotor tables or the O-grid (rejected). DTMB P1: CT −33% → +18% vs foam G1 — an overshoot, not parity.
- **Wall pressure image = wall momentum balance `grad p|w = rho (f - a_wall)`** (`gpu_tally_archimedes`, `gpu_tally_kutta_joukowski`, `gpu_rotor_comoving_fixed_point`). Resting, no body force: the zero-gradient copy. Rotor/MRF add centripetal (`p_g = p_s + rho_s a_wall.(x_s - x_g)`, `aspan`; O-grid `wallSpan`); conv plates hydrostatic (`p0 = p1 +- rho1 g hy`). rho, p sampled ON the normal from an all-fluid stencil; adiabatic image keeps T. No two-sample linear p extrapolation (growing wall mode with the central flux). n.div(tau) deliberately omitted (pairs with the tangential term the linear velocity image drops). Imposed test states must SOLVE the solved equations at the wall.
- **A two-sided ghost face reads its own side's image** (`gpu_comp_ghost_twoside`). Under ~2 cells of section a ghost holds ONE image; a face whose ghost normal points away from its fluid cell AND whose fluid normal is > 60° off gets a SIDE image (`ghostImage` along the fluid cell's normal), as rhs correction F(side) - F(shared) (`kSideRhs`, via `applyRhs`) and in every tally span (`kSideTally`). Covers resting, isothermal, moving (rotor tables; capacity covers all bins), MRF, focal, LES/RANS mu_t; NOT RANS scalars (warned). No usable side sample → shared, counted. A THICK body's sharp convex edge stays SHARED (ghost solid 2 cells behind along -n_g AND a deep cell within 3; side-imaging a square's corners made Re 100 cd 9% offset-sensitive). `faceFlux`/`faceFluxCurv` keep their bodies beside `faceFluxOf`/`faceFluxCurvOf` (value form moved NSCBC bits). Don't widen to near-tangent faces (one lens LE face moved Cn ~60 points).
- **SSP-RK3 weights sum to exactly 1 in FP32** (`gpu_mrf_conservation`): `Real(1/3) + Real(2/3)` = 1 + 3e-8. Steppers form `ca = Real(1) - cb` (Sterbenz, cb >= 1/2).
- **`--body cube` is a CUBE** (`dns::sceneCube`, the one definition): rotated-square section (`D` across the DIAGONAL), that tall in z, centred on `cz`, must fit in z; prism at `nz == 1`. `CutGeometry::make(RotatedCube)` has an exact partial-z aperture (bit-identical for a full-span slab). The z-invariant sampling short-cut must exclude cubes. Quasi-2D diamond = `--nz 1`.
- `gpu_runners`: one unquarantined smoke test per runner (exit 0, finite coefficients, healthy projection, stats rows; no literature band). It alone covers `--far tunnel` WITH walls end-to-end.
- Literature-band `val_*` tests are quarantined behind `-DDNS_VALIDATION_BASELINE=ON` by decision. `val_spindown` is the green canary.
- **Re60 cd anchors** (`docs/validation.md` adj. 6): `cyl_re60_n256_cd` 1.818652 (cut-cell, `--far tunnel`), `comp_re60_n256_cd` 1.952196 (ghost-mirror, `--far sponge`). [30, 20 pi] is NOT steady (sheds from t ~ 100, St 0.174). The +7.3% branch gap is NOT compressibility (cd FALLS with Mach; no closure with resolution); cause unisolated (wall AND laterals differ) — the band only pins the branches to each other.
- Blockage excess vs unbounded literature GROWS with Re — bands are repo-calibrated, not raw Williamson. TGV convergence is oscillatory.
- `--pitch`/`--yaw` are DEPRECATED, NOT aircraft angles (raw model axes); bake attitude into the mesh, leave both 0. Viewer needs `camera.up.set(0,0,1)`.
