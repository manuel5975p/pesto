## Ground rules

- ONE solver binary: `build/dns <flow|tgv|hit|channel|conv|flame|bench|prop|mesh>`. `dns --help` / `dns <sub> --help` are authoritative — read them, don't guess flags.
- `dns-ui` (scene editor, run cockpit, live viewer) links `dns_core` ONLY — never `dns_gpu`, never a solver. It RUNS a case by spawning `dns` and WATCHES it by mapping the run's shared-memory segment. `docs/ui.md`.
- Live results are shared memory: `--emit shm` (`src/dns/shmframes.hpp`) publishes planes, mask, 3D volumes under a SEQLOCK (writer bumps odd, copies, bumps even; reader copies between two equal even reads, discards a torn one). The solver NEVER blocks on a viewer. Volumes capped at 512 MB, else planes only.
- `--dry-run` validates + prints the resolved case (and DNS/LES label), no GPU or filesystem (exception: `--scene`, `dns mesh` and `--restart` read their input file's header facts in phase 1.5). Use it before every real run.
- **A restarted run equals the uninterrupted run BYTE FOR BYTE** (`dns flame --checkpoint-dt/--wall-limit/--restart`, `src/dns/checkpoint.*`, `gpu_restart_flame`; chains via `tools/chem/chain.sh`). Every host variable the loop carries lives in the loop struct; anything carried that changes results (warm starts) is checkpointed. Mismatched flags/binary/solver = exit 3 by name. No checkpoint flag = the solver bit for bit. The FV flame routes too (`runFvComp`, `runFvLowMach`, `gpu_restart_fv`/`gpu_restart_fvlm`): the device words raw at either precision, the low-Mach projection's warm start p and face flux phi carried; the MESH is identity (`mesh` record: polyMesh files + `--bc` content sha256, or `flags`): a changed mesh or `--bc` file = exit 3 even under the same path. The FV flame's `[thrust]` ledger too (combscale S1): device words `state.fv.ledger.{I,lo,om,omlo}`, host `loop.thrust.*` (records only with `[thrust]`); a changed `[nozzle]`/`[thrust]` section = exit 3 naming it (`bc.sections`, compared before the sha; `gpu_restart_fv_thrust`).
- Parsing is strict: unknown/missing/non-numeric flag = hard error. Exit codes: 0 ok, 1 CLI, 2 config, 3 input, 4 output, 5 no GPU, 6 resource, 7 numerical, 8 non-convergence, 77 skipped.
- `main` = Parse → Validate → Acquire → Run. Phases 1-2 touch neither filesystem nor GPU; phase 3 creates every output before the first `hipMalloc`.
- `std::expected` for anything a USER can cause; `assert` only for what a PROGRAMMER can cause (only if the validator makes it unreachable). Release is the build that runs — never assert-as-input-guard.
- Build: `build/`, CMake+ninja, **Release always** (never RelWithDebInfo — disk space), one GPU backend ON. ctest; GPU tests skip (rc 77) without a device. Always run tests with a timeout.
- TWO GPU backends, ONE set of sources: `src/dns/gpu/*.hip` is HIP; `DNS_WITH_CUDA=ON` compiles the SAME files through the shim `src/compat/cuda` (read its README). Never fork a solver per backend; never `#if DNS_WITH_CUDA` outside the shim — a HIP call the shim lacks is a build error ON PURPOSE: extend the shim in the same commit. App code uses `DNS_WITH_GPU` (not `DNS_WITH_HIP`). Backend name (`gpu::backendName`, `backend=` provenance) = `DNS_GPU_BACKEND_NAME` from the CMake backend branch, not a header `#if`.
- GPU arch AUTO-DETECTED (`CMAKE_HIP_ARCHITECTURES` / `CMAKE_CUDA_ARCHITECTURES`); wrong HIP arch = `getStatFunc` assertion. CUDA needs nvcc `-std=c++23` (configure compiles `<expected>`); CMake ≥ 4.3 needs the CUDA23 dialect flag taught, which the CUDA branch does.
- Long runs: `run_in_background`, act on the completion notification. No Monitor/sleep/until polling.
- **Every GPU run and every heavy CPU run (OpenFOAM, GPU ctest) goes through the job server**: `build/simjob submit (--gpu|--cpu) -t SEC -m MB --wait -- EXE ARGS` (multi-step / OpenFOAM: `--spec FILE.json --inherit-env`; timing measurements: `--bench`). Caps 1800 s / 16384 MB. One gpu + one cpu job at a time. Never run the GPU outside it. `docs/jobs.md`.
- Artifacts when asked to publish: dark mode; videos colormapped with curl and |velocity|.

## Layering

`cli/config` (pure parse+validate, `src/dns/config/`: one file per subcommand behind `config/internal.hpp` (`dns::cfg`, never included outside it); also `dns/scene`, `dns/remap`, `dns/sgs`, `dns/rans`, `dns/fvcomp_config`) → `bodies/geometry` (sdf + cut sampling; also `dns/curvmesh`, `dns/framemap`, `dns/walldist`, the FV mesh `dns/polymesh` + `dns/facemesh` + `dns/la/graph`, FV face physics `dns/fvflux.hpp` (DNS_HD) + `dns/fvgrad` + FP64 FV oracle `dns/fvref` + FV scalars `dns/fvrans.hpp` (DNS_HD) + FV case and frame plane `dns/fvcomp_case` + `dns/fvraster` + the flame probe `dns/fvflame` + the FV flame case assembly `dns/fvflame_case` + the conv FaceMesh layer `dns/fvconv`, host matrix/line patterns `dns/la/{ell,lines,structured}` + AMG setup `dns/la/amg`, the OpenFOAM case layer `dns/foamdict` + `dns/fvcase` + `dns/fvsimple` + `dns/foamio`, the time-accurate FV tables `dns/fvincomp` + `dns/fvlowmach`, FP64 oracle `dns/rans_channel1d`, implicit host line `dns/channel_line` + `dns/blockband` + `dns/pseudo_time` — header is constants/declarations only, so config may read its cap) → `gpu/{tunnel,bodyforce,les,rans,cutpoisson,cutflux,derived,comp_channel,comp_conv}` + the solver library `gpu/la` (mesh-agnostic: rows/slots, never faces) + the incompressible FV solvers `gpu/fv_simple`, `gpu/fv_incomp` + the compressible FV family `gpu/fv_comp` → `gpu/runner_{incomp,comp,channel,conv,fv,fvcomp,fvincomp,fvconv,fvlowmach}` → `output` (RunOutput, the one artefact sink; the FV path writes OpenFOAM time directories via `dns/foamio`) → `dns/drive` (library `dns_drive`: a validated Case onto meshes, ICs, runners and the sink, one driver per subcommand; `drive.hpp` = `readInputs` (phase 1.5), `dryRun`, `run`). `apps/dns_main.cpp` is argv + the phase order ONLY: no case, no physics, no runner call. The drivers hold no per-cell physics either: ICs, inflow rows, patch specs, solver constants are library functions (`dns/flow_ic`, `dns/flame1d`, `dns/lowmach`, `dns/fvflame_case`, `dns/fvcomp_case`, `dns/fvconv`, `gpu/bodyforce` `objectTallyBoxes`); a test calls them, never copies a driver. Preserve it; validated physics constants live at their definitions with the measured bracket.

## Invariants you must not break

- **2D is `nz == 1`, not a code path.** Periodic wrap cancels every z-stencil term; w stays exactly 0. Never branch z-terms out. Only solvers special-case degenerate axes (hipfftPlan2d, DCT skip, open box faces). Only z may be degenerate; `hz = 1` validator-enforced. Keep `*2d` parity tests green.
- **Ghost view is diffusion-only.** `gpu/ghostfill.*` mirror values never reach convection or the state (measured energy injection). Ghost faces have zero aperture.
- **Tunnel lateral walls are free-slip/Neumann.** No Dirichlet `u=uInf` far field (paints a wall vortex sheet).
- **Open/lateral BCs leave normal velocity free.** Relaxing v→0 or u→uInf laterally is a wall in disguise. Open tunnel: laterals slaved once per stage BEFORE projection; post-projection refresh is `refreshOnly=true` (re-slaving broke div u ~150×).
- **The compressible RK stage is FUSED: no materialized rhs.** `kCompStage`/`kCompStageCurv` write `out = ca*a + cb*b + cr*(-div F)` in one pass (`StageCombine`, `gpu/comp.hpp`): two stage buffers. (1) Stage output never aliases `cmb.a` — a boundary rhs hook is a second kernel re-reading `a`; stage 3 writes `q1_` and swaps. (2) Buffers swap, so no caller holds a raw device pointer into the state across a step.
- **NSCBC is an RHS overwrite** (`setRhsHook`), never a state overwrite. Inflow relax stays stiff (`--nscbc-etain`, default 100) WHEN THERE IS A FREESTREAM TO SAG. With none (static rotor) it is an acoustic mirror (0.81 back on a normal wave); there etaIn is worth 280×, the transverse coefficient 3% — don't reach for the transverse term first. Outflow needs the Yoo-Im transverse term (`--nscbc-beta`, default 0.5; 1.0 diverges).
- **`--nscbc-beta` is a constant; the right coefficient is not**: `beta_opt = cos t/(1 + cos t)` at incidence t (measured optimum 0.2 at 75 deg). `--nscbc-abc adaptive|modal` reads t off the face (`Tp/Lout = (1 - cos t)/cos t`) and is EXACT at every angle (Engquist-Majda symbol summed, no time history); normal incidence bit-for-bit. `adaptive`: per face cell, every open face, any mesh. `modal`: per DCT-II mode of the x-hi plane, exact eigenbasis only with free-slip lateral walls; rejected (never ignored) with `--open`, `--stretch`, `--focal`, `--ogrid`, `--body floor`. At 75 deg vs best constant: adaptive +34%, modal +1.0% (a pointwise ratio reads an AVERAGE angle). `docs/nscbc.md`, `gpu_nscbc_order`.
- **Measuring a boundary**: NON-WRAPPING difference (a whole-grid scan differences outflow against inflow across the periodic wrap; peeling cells also peels off a boundary-made sheet). State where the peak sits; show the number flat in time. An oblique reflection's measurement window closes in a square box past ~45 deg.
- **What the face cannot absorb is the sink's** (`gpu_comp_sink`, docs/nscbc.md). Central flux transports nothing at the mesh scale (group velocity `c cos(kh)` ≤ 0 below 4 cells/wavelength): 98% of a kh = pi packet strands; a 4dx vortical patch PARKS. `--nscbc-sink N` (+ `--nscbc-sink-amp`, (0,2] = SSP-RK3 bound): D4/sin^4 selective damping, conservative flux form, banded inside open faces, additive rhs UNDER the NSCBC overwrite. Zero on constant and linear fields — no freestream reference, so it cannot sag, wall, or eat the near field (resolved vortex: sink keeps 0.9999, strip 16 0.6813). Does NOT fix the resolved inflow mirror — that is etaIn's or the strip's. **ON BY DEFAULT (16, amp 1) for `--far nscbc` wherever defined** (uniform mesh, whole faces, band fits twice per open axis; Re60 cd +0.003%). `--nscbc-sink 0` = bare boundary bit-for-bit. The default stays off on `--stretch`/`--focal`/`--ogrid`/`--body floor`; an EXPLICIT sink there is rejected. The ONE exception to "no absorbing band by default" (no freestream reference) — it does not justify a sponge.
- **The lateral relax writes vorticity ∝ its rate** (`gpu_nscbc_order`): `etaLat c/L (v_t - tgt)` is the source, 0.20/0.80/2.16 of incident scale at etaLat 0.05/0.25/1.0 (free-slip walls 0.22). Plain `--open` = sink 16 + etaLat 0.05: residual 0.032, 7× below walls; open Re60 cd -0.003%. The walls' 0.22 is resolved vorticity parked in a quiescent box — only a freestream advects it out.
- **The inflow acoustic mirror is the sag guard's own** (`gpu_nscbc_absorb`). `--nscbc-etain-shear` rates the lambda = u family (L2, L3/L4) separately (default: follow etaIn, bit-identical); softening it 400× moves R_inflow 0.1% — a normal wave reflects off the `u = uInf` clamp itself, so only `--nscbc-etain` or the strip fixes the mirror. The family rate owns vorticity written under vortical load (0.0069 → 0.0050 at 100 → 0.25); its customer is turbulent inflow (L3/L4 at 100 clamp every eddy).
- **Sponge is NEVER a default — anywhere, any physics, any mode.** `--far sponge` (eats the near field) only when the user names it. Compressible default is `--far nscbc`. Struct/runner defaults stay off sponge.
- **`--far nscbc` alone only to Re800**; beyond, `--nscbc-sink 16` (preferred) or `--nscbc-strip ~ny/64` — validator enforces one.
- `--pot` off, or Q=0 ∧ a=0, is bit-identical (test-pinned). `csLes == 0` is bit-for-bit molecular DNS.
- Deterministic iteration/order wherever output depends on it.
- **Threaded host sweeps are bit-identical to serial** (`dns/parallel.hpp`: `CurvMetrics::build`, `sampleCut`, `compressibleBodyIC`, `classifyCompGhost` on the MRF and `--thin-seal` paths; `host_threads` byte-compares 1/2/3/7/hw/over-count). Rows as contiguous blocks (`forBlocks`) or an atomic queue (`forItems`), each cell its serial expression, writes to its own index only, one sdf copy per worker; a reduction keeps one partial per `forBlocks` block merged in block order and only if exact (min/max); a validator error is the lowest block's first. Never an FP sum across threads.
- **The editor covers `dns flow` and `dns conv`, both physics of each.** `DocState::sub` picks the subcommand; panels gate wholesale on it. Conv's SI face: height + temperature drop + material → Ra DERIVED (as size + freestream → Re). `dns-ui --check` has a COMMAND ROUND-TRIP GATE: exported argv → real `cli::parse` + `validate` must reproduce the document's case at the printed 4-significant-digit precision.
- The self-check owns `/dev/shm/dns_uicheck*`, clears them at BOTH ends, asserts nothing outlived it (a leak fails the NEXT `--check`). A stop before a run reaches its time loop is still not clean — `docs/ui.md`.
- **The editor owns no physics.** It CALLS `dns::sceneObjectBox`, `sceneBoxInside`, `needs3d`, `validSceneName`, `defaultSceneName`, `checkSceneNames` (`dns/scene.*`; `parseScene`/`buildSceneGeometry` route through them). Never restate a rule in `src/ui/` — move it, refactor the core caller onto it in the same commit. The editor's scene IS `parseScene(sceneToml())`.

## FaceMesh and the FV path (`docs/mesh.md`, masterplan_meshsolver)

- **ONE face-based mesh type, ONE geometry definition: OpenFOAM v2606's** (`makeFaceCentresAndAreas` fan, `makeCellCentresAndVols` pyramids, same operand order, FP64). `fromCurvMesh` writes a PolyMesh (`polyOf`) and routes through `fromPolyMesh` — never a second geometry code. Warped hexes: V differs from `CurvMetrics::vol` at warp order, stated, not "fixed". Pinned to checkMesh's printed digits (`test_facemesh` F1, local F8 on `mB`).
- **The reader accepts exactly what the OpenFOAM mesh tools write; everything else is REJECTED BY NAME** (`*.gz`, `processor`, AMI/ACMI, nonConformal, mapped, rotational cyclic, `#include`). Never "best-effort" a mesh.
- **2D is a one-cell-thick `empty` extrusion, not a code path**: every non-empty face's emptyAxis component of S and d is set EXACTLY 0 after `|S·e| ≤ 1e-12|S|` is verified.
- **Cyclic pairs are internal faces**; the lower source cell's side keeps S, Cf, srcFace; `d = (C_b + (Cf_a − Cf_b)) − C_a`.
- **Geometry is computed once in SOURCE numbering; orderings permute and re-orient (an own/nei swap negates S and d exactly)**: bitwise invariant under Source/Morton/ColourMajor. Internal faces sorted (own, nei, srcFace), CSR cell→faces ascending: the deterministic gather order. `CellGraph` slots: scatter in face order, no FP atomics.
- **Threaded host build is byte-identical at any thread count** (`forBlocks`, own-index writes, lowest block's first error; `test_facemesh` F5).
- `dns mesh` is host-only (`dns prop` precedent): no `--out`/`--backend`/`--seed`; `--dry-run` reads the manifest only.
- **The FV path is a separate solver family that RESTATES the structured algebra in `dns/fvflux.hpp`** (templated T ∈ double/float/`Dual<N>`). Never edit `faceFlux`/`faceFluxCurv` (or any hot kernel) to serve it. Pinned scheme: least-squares cell gradients + `AlongD` corrected face gradient (α 1) — on a uniform periodic box `FvRef` == `Comp::rhs` to 6e-15 (`test_fvref` G1).
- **FV boundaries are FACE FLUXES, never a state or rhs overwrite** (`fvBoundaryState` + `fvBoundaryFlux`). Adiabatic wall heat and mass flux are EXACTLY 0.0 by construction (G7, 45° non-orthogonal wall). Far = 1D characteristic state written as differences from the upwind state (freestream exact); the freestream is given CONSERVED so its primitives match an interior cell's bit for bit.
- **FV gather sums a cell's CSR faces in ascending face order; every pass writes only its own index** → byte-identical at any thread count (E2). No FP atomics, no cross-thread FP sums.
- **FV diffusive dt is the Σ form** `diff ρV/(μ max(4/3,γ/Pr) Σ_f corr·S)`: λΔt = −2·diff on any mesh/dimension (E3: 1.3× grows; E6: the 4/3 is momentum's normal stress, max(1,·) grew ×1.8e6 at Pr 2 on 100:1 cells). Never a per-axis `0.25 h²`.
- **A cyclic face's `Cf` may sit in the NEIGHBOUR's frame** (FaceMesh contract): FV code reads `FvFaceGeom::rOwn` (owner frame), never a raw `Cf − C_own`.
- **`gpu/la` is deterministic by construction** (`docs/la.md`): one thread per row or line, entries in ascending column order, no FP atomics; every inner product is a BATCHED fixed-order FP64 reduction (block partials, partial count from N only, shared-memory trees — no shuffles, wave32 = wave64) → reruns byte-identical (`gpu_la2`). No rocPRIM reduce or vendor sparse call inside it.
- **Compiled block shapes are a closed list** (`la::blockShape` + `internal::withShape`, edited together): B ∈ {1,3,5,6,7,9,11}, off-diagonals dense or 5×5 + scalar diagonal. Anything else is an error by name, never a fallback.
- **An FP32 iterate has a true-residual floor ~ε_f32‖A‖‖x‖/‖b‖** (Poisson 128² 1.5e-5, Pe 1e3 BiCGStab 2.4e-4 while the estimate reads 6e-6; 512² 1.28× the bound, `gpu_amg_fp32`). FP32 does not STALL below it, it certifies noise. A solve compared with OpenFOAM to solver tolerance runs `T = double`; FP32 for preconditioner-grade inner solves or a solve stopped at a floor above the noise.
- **FV precision: `--fv-precision fp64` = the parity mode, FP32 = the default with the floors** (`dns/fvprecision.hpp`, docs/fv.md "Precision"). ONE source: kernels, `Mesh`, `Ctl`, `RasState`, `SimpleImpl<R>` are templates on R; R = double is the FP64 solver BIT FOR BIT (`tools/fv/bit_perf.sh` with `FV_FLAGS="--fv-precision fp64"` + the full-length FINAL cases). Never fork a kernel per precision. FP32: fields, geometry, matrices, Krylov, AMG in float; every reduction (dots, normFactor, adjustPhi, continuity, forces) in FP64. Each FP32 solve stops at max(fvSolution tolerance, floor) — U 1e-6, p 1e-6, turbulence 1e-7, the first decade above the MEASURED tail noise (U ≤ 7.9e-7, p ≤ 6.8e-7, k 2.2e-8); relTol unchanged; a floor-only stop is logged `floor-limited`, never an error. The turbulence floor sets the nut FIELD (1e-7: 6.8e-3 of scale on rotor2 SST, 1e-6: 0.40; CT unaffected) — quote field parity in FP64.
- **BiCGStab restarts its shadow residual at |(r̂,r)| ≤ 2⁻⁵²|r̂||r|** (a measured Lanczos breakdown at it 254); 1e-12 restarted a converging run 27× and stalled it. Don't raise it.
- **gpu/la + FV performance kernels keep every output's FP expression, operand order and literal form verbatim** (`T(0) + ω s`, `s = T(0); s += …`; a product that must stay its own rounding: `#pragma clang fp contract(off)` + `__dmul_rn`). Only launch boundaries, load order and sync placement move (prefetched row loops, fused Jacobi, device α, deferred flags, `bicgstabBatch`, gradient / matrix reuse, lazy AMG refresh). Acceptance = BYTE identity vs the pre-change binary (`tools/fv/bit_perf.sh`); the pre-change kernels live on verbatim as oracles in `tests/test_gpu_la_ref.hip` (`gpu_la_ref`). A deferred failure flag is read before any result it guards reaches a field, same text and exit code.
- **AMG coarse values are a FIXED-ORDER FP64 sum of fine entries** (P piecewise constant: members' diagonal blocks, then the intra-aggregate slots, then each coarse slot's fine slots, all ascending) — no SpGEMM, no atomics; device == `la::amgGalerkin` BIT FOR BIT on every shape (`gpu_amg_refresh`). A new coarse-value path must keep that order or change the oracle with it.
- **Pairwise aggregation runs in Notay's priority order** (fewest unassigned strong couplers first, bucket queue). Natural row order stalled on a Morton snappy mesh (ratio 1.36 per level); keep the order when touching `pairwise`.
- **The K-cycle is a variable preconditioner**: PCG around `inner = 2` must be `KrylovOptions::flexible` (Polak–Ribière). Its inner dots and coefficients stay on the device (no host sync inside a cycle).
- **`dns flow --solver simple` IS `--polymesh`** (`docs/fvstructured.md`, `dns/fvstructured`): the flags name a CurvMesh; `polyOf` + generated dictionaries go to disk (`PREFIX/` or `--export CASE`), and the run reads that directory through `loadFvCase`. No second solver, no second geometry, no case built in memory for the run; `--dry-run` parses the same texts against a flags-only manifest (`FaceMesh::polyManifest`, the ONE definition of a structured mesh's patches and counts). A flag with no simpleFoam meaning is rejected by name. An immersed body has no body-fitted faces: rejected without `--ogrid`.
- **A revolved `polyOf` mesh collapses, it never carries a zero face**: the axis node columns merge to one node per j, axis quads become triangles, the cell side on the axis is no face (prism cells, no axis patch). The wedge's sides are `symmetry` patches, NOT OpenFOAM `wedge` (unbuilt): a `symmetry` value is `cos(dphi/2)` of the rotated one.
- **SIMPLEC needs relaxation**: `rAtU = 1/(1/rAU − H1)` is singular on an unrelaxed row; plain SIMPLE at α_U 1 blew up by iteration 20 on the laminar channel (generated α_U 0.99 there).
- **The one built fv::option is a constant specific U source** (`vectorSemiImplicitSource`, selectionMode all, Sp 0): V f on the matrix source, its own pass `kUForce` (absent = the kernels bit for bit). Everything else in `fvOptions` is rejected by name.
- **`dns flow --polymesh CASE` IS OpenFOAM simpleFoam** (`docs/fv.md`): UEqn.H + pEqn.H verbatim (fvMatrix relax/A/H/H1/flux, constrainHbyA, adjustPhi, SIMPLEC, setReference, p.relax, MRFZone) on the FaceMesh in SOURCE order. The case dictionaries are the input; every entry not reproduced exactly is REJECTED BY NAME (exit 3), every other `dns flow` flag exit 2. Gate: fields equal simpleFoam to ≤ 1e-12 iteration by iteration with tight solves (`gpu_fv_simple`); keep it there — a deviation is a bug, not a tolerance to widen.
- **On `symmetry`/`symmetryPlane` polyMesh patches every DERIVED field takes the constraint patch type** (OpenFOAM's `calculated` → constraint override): H's boundary value is `0.5 (H_P + R H_P)` (phiHbyA ~0 there), grad U's starts from `0.5 (G_P + R G_P Rᵀ)` before gaussGrad's normal correction. A `slip` BC on a plain `patch` is not that. Missing it was a 3.7% field error on IF1d only.
- **FV linear solves stop on OpenFOAM's measure** (Σ|b − Ax|/normFactor, `KrylovOptions::normFactor`/`minIter`); OpenFOAM's solver names pick ours, their iterates are not reproduced — a relTol-0.01 transient agrees ~1e-3, the fixed point to solver tolerance. p: scaled-V AMG, 2 Jacobi sweeps (measured best on F1, 34.9 vs 45.2 ms/it K-cycle).
- **The P5b MRF frame flux is OpenFOAM's POINTWISE `(Ω×(Cf−o))·S`** (MRFZone parity), deliberately not the telescoping edge form the masterplan prescribes for the compressible FV MRF (P9). Don't "fix" one into the other.
- **FV MRF is `MRFZoneList` zone by zone, in MRFProperties order** (`docs/fv.md` "MRF"): a face between two zones' cells gets BOTH frame fluxes (`phi − frame − frame2`, OpenFOAM's double subtraction; `gpu_fv_simple` mrf2 fails 13% without it). Every non-empty boundary face of a zone cell is MRF-included (phi 0, U_b = Ω×r — inlets, slip, symmetryPlane too) unless `nonRotatingPatches`. Zones sharing a cellZone, a zone cell on a cyclic face, a zero axis, > 8 zones: rejected by name. New variants (`limited`, more zones) are separate kernel instantiations: single-zone corrected runs are the P5b kernels bit for bit (BIT).
- **FV RAS = OpenFOAM v2606 `kOmegaSSTBase::correct` / `SpalartAllmarasBase::correct` verbatim** (`docs/fv.md` "RAS", `gpu/fv_ras.hip`): validate() after createPhi, correct() after the U corrector; omega's wall function updates ω and G BEFORE CDkOmega; the k equation sees the NEW ω; nuEff interpolated LINEARLY to faces. Laminar runs take the P5b kernels bit for bit (`Turb` instantiations, BIT). IF-T gate (`gpu_fv_simple`): fields ≤ 1e-9 of scale, residuals 1e-8, iteration by iteration — a deviation is a bug.
- **Boundary values follow OpenFOAM's field algebra, not intuition**: `calculated` nut = the model expression of the BOUNDARY values; fixedValue-derived patches (every nut wall function) IGNORE assignment, so Spalding's first guess is the previous wall nut; `bound()` max-assigns zeroGradient/kqR patches (stale) and re-evaluates slip/symmetry; the model's y_b is SMALL on walls, y_P elsewhere. Each of these moved fields measurably when wrong.
- **meshWave walks `primitiveMesh::cells()` order: OWNED faces, then NEIGHBOUR faces** — not ascending. With the 1% propagation tolerance an ascending order put 10k rotor2 cells 1e-3–14% off simpleFoam; with it ≤ 5e-12 (`fvwalldist_rotor`). The wall distance is a stated knob (meshWave | exactDistance) in every RAS label/report; decomposed simpleFoam runs the wave per processor (np 6 vs serial CT 5e-7).
- **`limitedLinear` cannot be tight-parity**: on a bit-uniform field r = 2000·sign(rounding noise) − 1, the limiter flips 0/1 with summation order (and with simpleFoam's decomposition). Tight IF-T cases use linearUpwind; limitedLinear is gated on a CONVERGED case (plate cf 2.6e-4). Don't chase its transient.
- **AMG coarse levels are launch-bound**, not work-bound: K-cycle on levels 1–2 plus levels ≥ `innerMinRows` (10 000) rows only, Jacobi on levels ≥ 1, dense coarsest ≤ 128 unknowns. Full K + MC-GS everywhere was 22 ms/it vs 3 ms/it at 1024² (`docs/la.md`); the single-block dense inverse is 218 ms at ~1000 unknowns. Re-measure (`test_gpu_amg tune`) before changing a default.
- **`constantNullSpace` projects the mean out of r and z in `Amg::apply`** — load-bearing: FP64 PCG on the periodic cut-cell operator broke down at relTol 1e-12 without it. b must be mean-free.
- **OpenFOAM's pressure matrix is reproduced exactly** by `|S|/max(n·d, 0.05|d|)` internal and `|S|/(n·d_b)` on a fixedValue patch (`foamLaplacian`, tests/la_test_util.hpp): AMG-PCG vs laplacianFoam PCG+GAMG fields agree to 1.1e-14 of max on B_G1s. Compare iterations at OpenFOAM's norm `Σ|b − Ax|/Σ|b|` (x0 = 0), not the 2-norm.

## FV routes (`--solver`, `--polymesh`, `--bc`)

- **`--solver structured|simple|fv` is one enum (`SolverKind`), default structured = the structured solvers byte for byte.** `simple` = simpleFoam on the flags' mesh (`docs/fvstructured.md`). `fv` dispatches on `--physics`: compressible = `gpu/fv_comp`, incompressible = `gpu/fv_incomp`. `dns tgv` takes `structured|fv`; `dns flame` takes `structured|fv` and `--polymesh DIR --bc FILE` (premixed model C0 only, `checkFvFlame`, everything else by name).
- **`dns conv --solver fv` is both models on a FaceMesh, `--polymesh DIR --bc FILE` the same route** (`dns/fvconv`, `gpu/runner_fvconv`): the box IS a FaceMesh with its floor at y = 0, so a binary polyMesh of it reproduces the stats byte for byte (`gpu_fv_conv` C6). `--physics` picks the schema. wall/slip/empty/cyclic only, plates flat at y = 0 and H, wall T equal to the flags' (`fvConvPlates`), by name. Height bins carry the plane statistics: on the box a bin is a row. `--hot-patch` is not built.
- **`--polymesh CASE` alone (no `--bc`, no `--solver`, no compressible physics) is simpleFoam.** With `--bc` or `--physics compressible` it is the FV solver of `--physics`, and PHYSICS PICKS THE `--bc` PARSER: `parseFvBc` (phase 1.5, before validate) or `parseFvIncompBcs` (Acquire). The schemas differ (`type` vs `kind`, ratios vs absolute velocities); a key of the other one is an error by name, never ignored. Routing lives once, in `validate()`.
- **`dns flame --physics lowmach --polymesh DIR --bc FILE` reads `parseFvBc`'s file** (`dns/fvlowmach` `fvLowMachBcs`: inflow, outflow, wall, slip); `far`, `burnt`, outflow `p`, `tback`, `y`: exit 3 by name, `--dry-run` included.
- **Each route's allow-list is its own**: `--compensated`, `--tt`, `--frame-*` compressible FV only; incompressible FV and `simple` `--emit stats|none`. A flag accepted by one route stays rejected by name on the others.

## Compressible FV family (`docs/fvcomp.md`, `gpu/fv_comp`, `gpu/runner_fvcomp`)

- **Every solver on every mesh goes through FaceMesh, no per-mesh fork.** `--solver fv` (O-grid, body-free box) and `--physics compressible --polymesh DIR --bc FILE` are ONE solver and ONE loop. An immersed body, the revolved O-grid and every structured-only knob are REJECTED BY NAME (allow-lists in `src/dns/config/fv.cpp`), never ignored. `dns flow --polymesh CASE` alone stays simpleFoam.
- **The face physics IS `dns/fvflux.hpp`, the passes ARE FvRef's**: double instantiation vs FvRef ≤ 1e-13 on every pass (`gpu_fv_comp`). A physics change goes in the template and the oracle moves with it. `faceFlux`/`faceFluxCurv` are never edited for it.
- **Cross-verification is the oracle, the table in docs/fvcomp.md its record** (solver pair, mesh, quantity, relation: bitwise / rounding / converging order p / converged limit, measured). Later phases fill the same table. A difference that plateaus is a bug or a stated model gap, never a wider band.
- **Same mesh + same scheme = rounding over a trajectory**: uniform periodic TGV, same dt, FV vs `Comp` (FP64) and `DeviceComp` (FP32), DNS and both LES models (`gpu_fv_cross` X1, X2). FV(FP32) minus structured stays ≤ 3× the FP32 run's own distance from FP64.
- **`Far`'s outgoing invariant reads the ISENTROPIC `c` of p, never `c_P`** (`cF (p_P/p_F)^((γ-1)/2γ)`; `gpu_fv_far` X5). `u_n + 2c/(γ-1)` holds at constant entropy only: `c_P` made the warm wake a pressure source of relative size M, cd +0.38% flat under h. Fixed: -4.1e-4 at 192x96, order 1.8; the whole structured far row on FV agrees to 7e-5. An R ladder at fixed `--ny` is also an h ladder (h1 grows with R).
- **FV gravity is two additive passes, never a kernel edit** (`FvCompConfig::gravity`, `kFvWallHydro`, `kFvGravity`; FvRef carries the same): `m += cr rho g`, `E += cr g.m` of the stage state after the gather; on every Wall/Slip face `dp S`, `dp = rho_P g.r` (`fvHydroWallDp`), the structured plates' hydrostatic image. Zero: neither launches. Open patches and moving walls are rejected by name (`FvRef::make`): no hydrostatic ambient. Same discrete balance as `kGravity` + `kConvWallY` in the interior: no well-balancing, a non-orthogonal mesh leaves a stated residual (docs/fvcomp.md "Gravity"): smooth ~order 2, random 0.3 h 1.1% of Uff, enough to misread the height-binned nuFlux (0.61 at rest) while the face Nu holds. FV `--cfl` is 2x smaller a dt than structured (Sigma form), so plain FP32 drops 2x the updates: conv defaults compensated (192 x 96 Nu -2% plain; compensated = FP64 to 3e-4).

Compensated FP64 = the increment form + a double low word (`gpu/word2d.hpp`; G4.1 1.65e-16 flat at 30 cells, 3.4e6 steps; +3.1% per step); off = bytes.
- **The FvBc table is rows, a face holds a row index** (`BndRow::bc`): one row per patch, then `FvConfig::bcRow`'s per-face rows, same kind as the patch's (the jet's inflow, `fvJetRows`). The ramp rewrites patch rows (`setBc`), a kind never changes. `make` validates the converged (frac 1) table.
- **Frames on any FV mesh are a uniform plane** (`dns/fvraster`): containing cell per pixel (walk across faces from the nearest centroid), mask 0 outside. No index-space raster, no blending, ONE path for O-grid and polyMesh.

- **The compressible FV stage is a MODULE INVENTORY** (`dns/fvmodules`, docs/fvcomp.md "Combinations"): every module (LES smag/sigma, TFLES uniform/dynamic + Charlette, RANS SA/SST, C0, C1, gravity, bodyForce, steady LTS, compensated, FP64) and EVERY pair's decision is one table, read by `FvRef::make`, `DeviceFvComp::make`/`localDt`, the CLI's pair checks and the generated docs table. A pair goes live only when `gpu_fv_matrix` passes its cell (inert bitwise, rest/pow2 Y/mass/energy/Z == tracer, FvRef 1e-13, numbering, rerun) and it has its physics number (`gpu_fv_matrix_phys`), in the same commit. Refused by physics: species + RANS (no mean-rate closure), RANS + gravity (no buoyancy production), LES + `--steady` (time-accurate); by code: species / gravity under LTS (`kFvChem`, `kFvGravity` take the bare cr). Gravity keeps refusing open patches (no hydrostatic ambient), so `dns flame --gravity` stays refused. Matrix states are UNTIED: the TFLES dynamic sensor's T-gate is a switch, an exact tie flips by O(1) under rounding.
- **FV species are rows 5.. of the state, off = byte for byte** (`FvChem`, docs/fvcomp.md "Species"): `nY == 0` launches no species kernel. They ride the face's own `F[0]`, read from the flux row. On a uniform mesh it IS `Y_up - Y_upup`, so FV == structured species to rounding on a periodic box (`gpu_fv_flame` S8). No NSCBC, no sink on a FaceMesh: a flame box is fresh `Far` + burnt `Outflow`; an `Inflow` + `Outflow` pair is an organ pipe (the jet takes it, it must hold u: read past t ~100).
- **FV two reactants are `FvChem::ox >= 0`, their own instantiations (`kFvSpCell`, `kFvSpFace`, `kFvSpBndFace`, `kFvChem` `Two`); `ox < 0` is the premixed kernel bit for bit.** ONE MC limiter per face, `fvThetaVote` over every species with |d2| >= 2^-24, d1 virtual as `fvFaceY`'s; face value linear in Y, so Z(Y) == a carried tracer within the FP32 walk.

TFLES with it: refused by name (thickening is premixed C0's).
- **FV species LES / TFLES = the structured `Eddy` / `Thick` algebra on faces** (`fvEddyRhoD`, `fvThickRhoD`, `fvThickEnergyFlux`, `kFvSpFace` `Diff` instantiations; FvRef carries them; docs/fvcomp.md "Species LES and TFLES"). The sensor's max filter WALKS FACES (`fvTflesWalk`: the face most aligned with +-e_a, a boundary face stops, cyclic wraps): on the uniform box it IS the structured filter (L5). Premixed only; off and `--tfles 1` = the DNS bit for bit.
- **The jet's inflow is a fixed FACE, not a held cell** (`FvBc::diffusive`, docs/fvcomp.md "Diffusion flame"): `Inflow` rows, Fick, Fourier and stress through the face. Without them 5% of the fuel never enters (tip 46.1 vs 47.2 foam); `Far` rows sag the inflow u under the flame (tip 43, fuelIn -11%). A soft inflow is not an option for a jet.
- **A `characteristic` Outflow is the jet's, no one else's** (`FvBc::characteristic`, `fvJetRows`): while the flow leaves, p_out with the owner's entropy and outgoing invariant. The plain row drains a cell below p_out at p_out's density: at 30 deg shear the jet's outflow cells evacuated at t 23 (rho 6e-4, dt collapsed). Off = the row bit for bit. A sheared jet still diverges late, in the interior (issues.md 78c).
- **FV gravity is a face term of the internal faces, both cells add it, unsigned** (`fvGravityFace`, `fvHydroRho`, `kFvGravFace`, `kFvGravity`): `(g.d/2) rho_f S` on momentum, `(g.d/2) mdot` on E. It stands against the pressure sum's `(p_N - p_P)/2 S`, so T linear in the height + its hydrostatic ln p is a fixed point on ANY mesh, to rounding (`test_fvref` W1, `gpu_fv_conv` C8). `rho_f` is `L(p)/(R L(T))`, log means: a plain mean is not path independent and leaves the loop sum. A Wall or Slip face adds nothing: its hydrostatic image and its share are one number, opposite. `Sum V (E + rho phi)` telescopes (W2). Never put `rho g` back on the cell: on a random mesh it fights `(1/V) Sum d S / 2 != I` (1.1% Uff, nuFlux 0.61).
- **FV open patches under gravity read the hydrostatic ambient at the OWNER'S CENTROID** (`FvConfig::ambient`, `fvAmbientRows`, docs/fvcomp.md "Hydrostatic ambient"): one FvBc row per Far / Outflow face, p_a = `candleAmbientP` (the ONE column definition), no kernel edit. Not the face centre: a boundary face carries no gravity share, so its pressure is the owner height's, as a Wall's is p_P; the rest crosses an open face as P == F, exact on any mesh (W3; quiescent candle FP64 max|u| 8e-13 U, FP32 6.3e-4 vs structured 1.21e-3). `FvRef::make` checks every open row against the column by name; gravity + Far/Outflow without `ambient` = refused. The candle's top is a `Far` row under g > 0: the jet's fixed-p Outflow rang as an organ pipe the flame pumps (p/p0 +-0.7%, tip 6.48 vs 7.13, extinction at 4 cells/l). g 0 = the FV jet byte for byte.
- **FV RANS = the structured closures on faces** (`dns/fvrans.hpp`, `docs/fvcomp.md` "RANS"). `dns/rans.hpp` stays the ONE home of the constants. `mu_t` rides the LES `nut` slot, so the mean-flow kernels are the LES instantiation, untouched; a Wall face carries the molecular stress and heat BIT FOR BIT the laminar ones. Scalars ride `F[0]` (uniform 2^-13 stays exact), boundaries are face fluxes: Wall = Dirichlet diffusion on molecular mu, Slip nothing, open = `F[0]` upwind, no diffusion. nu~ 0 / k 0 = the laminar mean rows byte for byte (R3). `--rans none`: no row, no pass, no buffer.
- **FV wall distance = exact to the Wall-KIND patches of `--bc`** (`fvRansWallDistance`), not the polyMesh type word, not meshWave (refuses cyclics). Its srcCell is ranked first: `fromCurvMesh` holds Grid::idx there, a raw `fvWallDistance` wrote past its array.
- **FV `--steady` = `DeviceFvComp::localDt`**: `lts[c]` in every stage writer, compile-time instantiation; off = bit for bit. LTS drifts the mass and the channel is a one-parameter family: compare with the oracle AT the march's mass. Its state is compensated in FP32 without `--compensated`, plain in FP64 (`fvCompStateCompensated`, config.hpp): the ONE rule the driver runs and the label states (a label reading the flag alone misstated both, N22).

- **`--turb` on FV and low-Mach is the IC + per-face inflow ROWS, never a stage term or a device generator** (M5, `dns/fvturb`, `dns/lowmach` `lowmachTurbRows`; docs/fvcomp.md "Turbulence", docs/chem.md "Low-Mach turbulence"). ONE generator (`dns/turb_ic`): FV evaluates its Fourier sum at the centroids (`turbAt`) and swept past the inflow face centres (`TurbSweep`, X = Σ U dt FP64 host, rows set before each step, held over its stages: `DeviceFvComp::setBcRows`, `DeviceFvLowMach::setInflow`, `DeviceLowMach::setInflowTurb`); the structured low-Mach IC is `turbBoxAt` on the MAC faces, its tangential inflow the `Turb` instantiation of `kLmMomT` (v_face = the row; off = the antimirror bit for bit). u' 0 rows = the laminar tables BYTE FOR BYTE (gpu_fv_turb T2, gpu_lm_turb L1, the matrix cells' inert gate). FV box IC == the structured `turbBox` field to rounding (direct sum vs c2r, 4e-14 u'). Compressible FV vs structured on one box: rounding (X3); the inflow is a stated gap (Far face vs NSCBC cell). Low-Mach FV vs MAC: a scheme gap of order 2 (L2). Modules `Turb` in fvmodules / lmmodules; `--polymesh`, the low-Mach burner, low-Mach checkpoints: refused by name.
- **A reacting-nozzle IC is a steady state of the solved equations**: chamber slabs on the Rayleigh line (m, p + m u, cp T + u^2/2 + q(1 - Y) conserved: `fvRayleighBurnt` at q(1 - Y)), never `premixedPoint`'s low-Mach T = sigma Tu (+1.71e-3 in T0: an entropy slug through the throat at t_e ~ 40 tau, inside every gate window; mdot dip -7.1e-4 -> -1.05e-4, G4.6 mdot -2.2e-4 -> +1.5e-6).

Never a DFT peak list (bins of the record). A twin's Re* is its own rung's y* (the 30-cell twin at the 15-cell y* moved Cd 1e-6).

## Time-accurate incompressible FV (`docs/fvincomp.md`)

- **`--solver fv` / `--bc` under `--physics incompressible` is the MAC solver's time scheme on a FaceMesh, not simpleFoam**: `gpu/fv_incomp`, `gpu/runner_fvincomp`, `dns/fvincomp`. `dns flow --polymesh CASE` alone stays `gpu/fv_simple` byte for byte. No immersed wall: a structured body needs `--ogrid`. Every other flag is rejected by name.
- **Convection is the compact skew form `(1/2V) sum phi_f u_N`, a skew matrix for ANY phi**: conv KE 0 to rounding (`gpu_fv_incomp` T2) whatever the projection did. The 1/2 is forced: the skew part of any compact `phi(w u_P + (1-w) u_N)` is `phi (u_N - u_P)/2`, the weights drop out. So on a non-smooth mesh the order is 1, not a bug to chase (below).
- **kg uses the LEAST-SQUARES gradient of p, never G**: G carries fp, fp carries kg; that recursion has eigenvalues `-s^2 +- s sqrt(1 + s^2)` on a parallelogram of shear s and diverged in ~7 steps at 41 deg. `phi` closes on the last kg whatever nCorr.
- **G is the Perot reconstruction `(1/V) sum +-r_f fp_f`**: exact for linear p on any mesh, the central gradient on a uniform one; fp = 0 on a Neumann face gives the wall cell half the top face's correction, the no-slip linear profile. `phi*` interpolates the predicted velocity (Mahesh): the steady fixed point moves with dt at O(c h^2 D3 p).
- **The pressure matrix is geometric**: built, uploaded, AMG-factored once. It solves `A p = -div(phi*)/c`, so p is the pressure at every stage and warm-starts across stages. Stop: `max(tol |rhs|, 4 eps_R |gross flux/c|)`.
- **Same mesh + same BCs vs `--polymesh` simpleFoam is the FV path's sharpest oracle** (`tools/fv/incomp_cases.py`, `test_gpu_fv_incomp fixedpoint`): O-grid fields converge order ~2 there. FV vs MAC is two walls; MAC is unconverged at N 256 (Re 40 cd 2.0809, 2.0654 at N 512, FV ~2.042, issues.md 79a). Don't read a gap off it, don't widen a band on it.
- **A wall face carries OpenFOAM's whole stress** (`wallStressRest`, `dev2(g_b^T)`, g_b one-sided along n), so a mesh with a wall runs the cell gradient every stage. The Laplacian alone: cd +2.9e-2 vs simpleFoam at N 128, budget open. **Wall p in a force is p_P**, the value the momentum equation applies; `p_P + G.r` moved cd with dt. Closing the Perot sum at walls made it worse.
- **`DeviceFvIncomp::step` needs dt near the last step's**: phi holds the last c's Rhie-Chow term, so a step of f dt moves u by (1 − f) of it for ANY f << 1, p by 1/f; 1e-12 dt diverged (T7). Reach an end time in equal steps (`rem / ceil(rem / dt)`); never clamp a last step. It was issue 79c and part of T6's 8.6e-2.
- **A lid corner cell is a scheme number**: all-cell max vs simpleFoam does not shrink (0.10), a fixed distance off it does (order > 1.7). T6 gates outside 2 cells of a lid corner.
- **The Boussinesq force is a FACE force** (`kBuoyF`, `DeviceFvIncomp::make(..., T0)`): `phi* += c B_f`, `B_f = (T_f - Tref) betaG.S`, the reconstruction reads `fp - B_f`, so a hydrostatic state cancels face by face: rest residual 3e-10 (FP32) on the uniform box. A cell-centred force leaves the wall cell half a hydrostatic gradient per stage. A wall face stays Neumann and carries no net force (B_b in phi* would break compatibility: its sum is the plates' T difference). `kGradP`'s wall difference is the hydrostatic image `dpB` (without it the deferred kg reads zero normal gradient at a wall: rest residual 15x, sine 0.08). FP32 |div| floors at 1e-4 (the flux carries c B_f; FP64 4e-7, same Nu)..
- **T is the momentum's scalar twin** (`kFaceT`, `kBndT`, `kGatherT`): skew-symmetric central on the same phi, conv T energy 0 to rounding (`gpu_fv_conv` C3), a no-T wall carries EXACTLY 0. T0 empty: not one thermal kernel launches, the solver bit for bit.
- **The incompressible FV stage is a module inventory too** (`dns/fvimodules`, docs/fvincomp.md "Incompressible combinations"): LES smag/sigma, T, gravity live; RANS and species REFUSED ALONE by name (simpleFoam owns RAS; constant-density species: no oracle, no consumer, issues.md FI1). Read by `validate()` (`fvIncompModules`), `DeviceFvIncomp::make` (`fviModulesOf`) and `gpu_fvi_matrix`. LES + T = the eddy heat flux `nu_t,f/Pr_t` (`kLesPrt`) on INTERNAL T faces only (`kFaceT<…, Les>`), nu_t 0 = molecular bit for bit. T at betaG 0 is a passive tracer: no force pass runs, momentum bit for bit.
- **Offsets are not face data the FaceMesh zeroes**: `rO`, `bR` are set exactly 0 along the empty axis in `buildFvIncompSetup`, else `w` picks up the mesh's z rounding through G.

## Low-Mach FV (`docs/fvincomp.md` "Low-Mach")

- **`dns flame --physics lowmach --solver fv | --polymesh DIR --bc FILE` is `gpu/lowmach`'s stage on faces**: `DeviceFvLowMach` in `gpu/fv_incomp`, holding a `DeviceFvIncomp` impl for the mesh view, gradients, `project()`, AMG; `gpu/runner_fvlowmach`, `dns/fvlowmach`. T predictor, D, stage writes, compensated words, order of passes are the structured expressions, operand for operand: same mesh, same dt, FV(FP64) vs structured(FP32) is rounding (`gpu_fv_lowmach` L7). A change to one moves the other.
- **The pressure matrix is GEOMETRIC, no 1/rho**: the projection is on the MASS flux (`m = m* - cr fp`, `rho u -= cr G`), so A and its AMG are built once per run. Target V D inside `kRhs`'s bracket. No pure Neumann case: `Sum V D != 0` in a closed box (P0(t) not built), refused by name.
- **Momentum is `m (u_o + u_n)/2` conservative, NOT `DeviceFvIncomp`'s skew form**: the skew half is `u_P div(phi)/2`, and div m is not 0. The 1D flame never reads momentum; a change there needs the 2D row.
- **One limiter over Y_k and T (`fvThetaVote`), central where the upwind cell has no second neighbour** (`FvLowMachTables::first`: a boundary face behind that cell, within 60 deg). So a uniform mesh is `sharedThetaOf`'s stencil to rounding, boundary cells included.
- **`kLmfGatherS` is `fp contract(off)`**: rho and every rho Y go through one source, and the fuel row's `- omega` fused its write differently: 2e-8 off rho's bits (L1). Don't take it off.
- **Energy: the semi-discrete balance is an identity (rounding, L3); the march's closes at ORDER 1 in dt** (R_T reads the stage's input m, continuity its output m) and vanishes at a steady flame. `gpu/lowmach`'s algebra verbatim, same one-stage lag. Not a bound to tighten; a T_f-weighted pressure equation is another scheme.
- **Low-Mach diffusive dt sums `|S|^2/(S.d)`, not `corr.S`**: equal on an orthogonal mesh (structured dt there), `corr.S` diverged at 67 deg. Don't unify with the compressible rule without that case (`--meshes all`).
- `totals()` reads the last stage's T*, V D; `budget()` rewrites them. Read `totals()` first.
- **Low-Mach LES / TFLES (M4) are their own instantiations on BOTH solvers, off = the kernels bit for bit** (structured `kLmNut`, `kLmTemperature`/`kLmScalars<…, Diff>`, `kLmCellPass<…, Eof>`; FV `kLmfNut`, `kLmfFaceT`/`kLmfFaceY<…, Diff>`, `kLmfFaceM<…, Les>`, `kLmfCell<…, Eof>`). mu_t = rho (C Delta)^2 rate per stage; mu + mu_t in the stress; T and species rho D + mu_t,f/Sc_t on INTERIOR faces only (Sc_t = Pr_t = `kLesPrt`, Le_t 1); TFLES F E rho D + (1 - Omega) mu_t/Sc_t, omega E/F. Laminar limit bitwise (TFLES F 1 without LES, sigma on a planar flame). FV vs structured: TFLES rounding; Smagorinsky a scheme gap of mu_t (cell velocity definitions), order 2 — not a bug. Pairs live in `dns/lmmodules` (ONE decision each: TFLES refused with C2/C2b, open laterals, rim; LES with rim). dt and stats read the eddy fields of the CURRENT state (`refreshEddy`): the restart byte rule holds.
- **An FV low-Mach open face is ONE rule by its own flux's sign** (`FvLowMachTables::bOpen`; empty = bit for bit): T, momentum and the face p `-beta rho_a u_n^2/2` read the stage input's sign, the species flux the PROJECTED one's (the input's carried ambient Y_O out: -2.6e-5). Normal viscous stress = the cell's (zero normal-stress gradient), tangential one-sided: tau_nn = 0 is another BC (boundary rows O(1) off MAC, l1 grew with h).

Flame aspect follows the fuel Péclet number (W 2: a needle; W 1: the teardrop); W ≥ 1.25 flaps (period ~4 l/U at W 1.5).

The chamber runner puts `ghost.applyRhs` in its rhs hook (NSCBC → re-carry → sink → species sink → wall faces → injector).

## DNS vs LES vs RANS labeling

Only dissipation is physical ν; DNS iff the grid resolves the body BL (~D/√Re). `--les Cs` FILTERS — statistics depend on grid AND Cs, `cdf` uses ν only. If a run needed `--les` to survive, label it LES everywhere (reports, artifacts, memory) with Cs AND model (`--sgs smag|sigma`). σ-model (Cσ ≈ 1.35, NOT a Smagorinsky Cs; `dns/sgs.hpp`): zero in laminar shear / any 2D state, transition-capable; rejected at nz == 1. 2D + `--les` = regularized 2D Euler, qualitative only.
LES nut takes the RANS wall image (`setMutHook`: odd at walls, even on mirror rows); tallies carry SGS (`gpu_les_wall`, `gpu_les_tally3d`).

A RANS field (`dns channel --rans`, `docs/rans.md`) is an ensemble-mean MODEL output, never a grounder. Label `RANS SA-neg` / `RANS SST-2003m` / `RANS SST-Vm` (FV path: `RANS kOmegaSST (OpenFOAM v2606)` / `RANS SpalartAllmaras (OpenFOAM v2606, ft2 on|off)` + the wall-distance method) plus mode (`steady (local time stepping: pseudo-time, not time-accurate)`, `steady (implicit Newton pseudo-time: not time-accurate)`, or `URANS (time-accurate)`) everywhere. Invariants:
- **RANS off, and ν̃ ≡ 0 / k ≡ 0, is DNS bit for bit** (`gpu_rans` G1/G2). μt rides the LES `nut` slot; the ONE hot-kernel edit is `cmb.cr` → `cmb.crAt(c)`. `faceFlux`/`faceFluxCurv`/`kPrim`/`wall_ghost.hpp` untouched.
- **μt is ODD across wall ghost rows** (`kMutMirrorY`) → 0.0 on the wall face; never from ghost scalars. Ghost scalars mirror the SPECIFIC value with the ghost's density; SST ω images TMR's 60ν/(β1 d1²).
- **Every `cmb.cr` consumer uses `crAt(c)`**; additive hooks take the whole `StageCombine` (bare cr under LTS converges to lts·R + f = 0, G7).
- **Residual = explicit-mode extra stage** (ca = cb = 0, cr = 1, hooks in, scalar kernel in residual mode), never state differencing.
- **SA-neg is TMR SA-neg WITH ft2.** ν̃ never clipped; SST's k/ω guard is COUNTED (`floorHits`).
- **Scalars convect first-order upwind on the mean mass flux** — verbatim `faceFluxCurv` expression (G3: 0 ulp). Mean flow gets NO added dissipation; a stall is a user decision (U1).
- **Per-cell diffusive dt is RANS-only**; DNS/LES `stableDt` byte-identical (its LES bound is over-conservative on clustered meshes — recorded, not fixed).
- **FP32 steady residual cannot certify convergence**: it stalls at |R|·dt ≈ ulp(q)/2 (resid ~1 vs 0.04 at the oracle state) while ub is still 1.6% off; the solution does reach the oracle (`gpu_rans` G9 plain, G10 compensated). Pin against `rans_channel1d`, not a residual.
- **`--steady TOL` stops on INTEGRALS** (`dns/steady_stop`): ub, bulk T, ∫ρν̃ | ∫ρk, ∫ρω each within TOL of a geometric extrapolation over the history's second half, every window row monotone to 2^-20. Keep SEVERAL series (ub alone stopped 2.8% low) and the monotone check (a damped oscillation stopped 8.7× early). Monitor bulk T, not T − Tw (noise 5e-6 vs 3e-8). `gpu_runners`.
- **`--steady` marches a COMPENSATED state** (`DeviceCompState::lo`, Kahan low word; kernels read hi). Every stage write (any new StageCombine consumer too) goes through `gpu/internal/stage_write.hpp` (`stagePut`/`stageAdd`, a + cb(b − a) + cr R, exact as ca == 1 − cb). Plain vs compensated is a COMPILE-TIME switch (`withCompensation`) — a runtime branch moved NSCBC bits via FMA contraction. A new state OVERWRITER on a compensated state zeroes its cells' low words (the channel wall does). Fixed point 2000× tighter, still ~10× above the static floor — hence the integral stop. `--compensated` applies it to a time march (plain FP32 URANS diverges as dt → 0; docs/rans.md).
- **`--steady-scheme implicit`: rhs = GPU residual-mode stage; `dns/channel_line` only preconditions** — its R never reaches an update (`gpu_rans_implicit` I1/I2). Explicit stays default, byte-identical.
- **One column, broadcast**: host FP64 column, device FP32 copy in every column. Exact only because the RANS channel mean is x/z-homogeneous (homogeneous IC, `--kick` rejected) — never generalize. ρw stays 0.
- **Total mass is pinned by projection to the IC mass** (the steady equations are a one-parameter family in mass; LTS drifts it, −7.8e-4).
- **Line Jacobian is CENTRAL FD in FP64, K = 1 SA / K = 2 SST.** Forward FD stalled Newton on SST Re_τ 1e4 (centreline, v = 0 kink); SST K = 1 has a 0.70/iteration tail or diverges at CFL ≥ 300.
- **Never build J by FP32 FD of the GPU residual** (step window non-monotone, case-dependent).
- **The stop listens only after an undamped step AT the CFL cap** (else it certified a damped stall 1.1% off). 27–28 iterations, ≤ 8e-8 off the oracle, Re_τ 180 to 1e4.
- **O-grid far boundary is its own characteristic row**: `--nscbc-*` and `--pot` rejected with `--ogrid`; Re > 800 only warns.
- **`dns flow --steady` stops on a JITTER FLOOR (`steadyFloor`); the channel keeps `steadyRemaining` bit for bit.** External integrals jitter white at the FP32 floor (pressure coefficients amplify p's ulp by 2/(γM²)). Trend from block means vs a noise limit; cd/cdf certify on trend + √2·jitter < TOL; monitors also need jitter ≤ 2^-10 (`kSteadyJitterMax`). Per-series trend/jitter line always printed. TOL below the jitter never certifies — by design. **The iteration it stops at is a first passage of noise through TOL, never a gate**: `gpu_sa_wedge` 111000–185400 under a 1e-6 nudge of M or Re, cd within 5e-5, identical on rerun; gate the first `remaining` below a few TOL (98600–113000).
- **The wedge has TWO azimuthal widths**: ρ (`aov`) for the time march, ρΔφ (`aovSteadyZ`) for the steady local dt only, with a RELATIVE collapse guard (1e-3 × first dtRef; axis dtRef ~7e-7). Widening the time-march width caused a pseudo-time limit cycle.
- **Axisymmetry = mesh + ghost hook**: axis faces S == 0 with the analytic limit metric; ghost columns carry R_x(π) continuation on their real neighbour's metrics.
- **Immersed RANS scalars**: ghost k image EVEN and quadratic (a²·Σw·k; odd fed negative k into corners); interface faces convect ν̃, k at wall value 0; open-face scalars re-carried by mean-flow density after the NSCBC hook (`rans::openScalarConsistency`); μt ghost clamped so μ + μt ≥ μ on every staircase face (`μt_g = −min(a Σw μt_s, fluid face neighbours' μt)`; odd image hit −39 μ, `gpu_rans_immersed` (e)). Label `[immersed ghost wall: first-order wall position, NOT body-fitted]`.
- **Flow NK**: R always the GPU residual-mode stage, dissipation only in P; lexicographic line-GS only (red-black stalled at 200 Krylov); FD step 2^-14. In NK kernels stage operands with unrolled loads first — a load-wait-use loop serializes (59 → 13.4 ms).
- **OpenFOAM parity**: v2606 SA defaults ft2 OFF, Prt 1.0 — set `ft2 true`, Prt 0.9. `exactDistance` fails in parallel: run serial. A RAS parity number is quoted vs SERIAL simpleFoam: np 12 moves its own rotor2 SST CT 2e-6 (meshWave/GAMG decomposition; dns reproduces serial to 2e-8). **A parity number names OpenFOAM's U scheme**; reference is central `linear` (`tools/parity/sph1e4.py`) — linearUpwind moved SST cd 2.8–7.6%, L_r 14–28%.
- **SST-2003m Re 1e4 wedge limit cycle is the model's own unsteadiness** (URANS: cd 0.404–0.424). Don't "fix" it in the explicit march; report the URANS time mean, labelled URANS. SST audit found no model difference (`sstRestatement`, `gpu_sst`).
- **A front sawtooth in a steady LTS march = no steady wake**, not a front bug (LTS concentrates wake radiation in fine front cells). Coarse-wedge exit 8 accepted; only dissipation cures it.
- **Full revolution (`--ogrid --body sphere --nz N`, N even ≥ 4)**: axis ghost columns VERBATIM copy (i_s, j, (k+N/2) mod N), Cartesian components unrotated. aov[2] = 1/(ρΔφ); `aovSteadyZ` empty.
- **Full revolution is exactly π-symmetric**: odd azimuthal modes NEVER arise from rounding, so an untripped run certifies an unstable symmetric state. `--ogrid-trip A` seeds m=1 (laminar Re 250: cd 0.710, cl −0.065; Johnson & Patel ≈ 0.70 / 0.062).
- **The full revolution trips by DEFAULT** (`kOgridTripDefault` 0.05 U, bracket in `ogrid.hpp`). `--ogrid-trip` valid on every O-grid except the axisymmetric wedge; default 0 elsewhere (bit for bit untripped, as is `--ogrid-trip 0`). `--kick` REJECTED with `--ogrid`. Trip always in the label. The steady stop carries `cd+cl` and `cd+cs` — cd is EVEN in m=1 and stays flat while the mode grows. Never drop them.
- **`--init-from PREFIX` revolves a converged wedge** (`revolveWedgeState`), checked by meridional nodes, closure, Mach: mismatch = exit 3, never a silent re-grid. An untripped wedge start is not evidence of 3D stability.
- **Full-revolution DNS dt is a TRUE axis limit** (axis cells' azimuthal width; stable 2×, diverges 3×). Only implicit azimuthal diffusion on the axis ring or coarser axis cells remove it.
- **3D equals the wedge** at Δφ = 2π/N to the jitter floor (cd 4e-5); second order in Δφ; polygonal body is the discretization, qRef stays the circle's.
- **URANS turbulence scalars are first order in time** (point-implicit stage quotient; `gpu_sst` (a)). Steady fixed points unaffected.

## Known gotchas

- **`offsetsAt` (gpu/index.hpp) has `gidx`'s contract**: one cell out of range MUST wrap. Sparse boundary/surface kernels ask for `j-1` at `j == 0`; offsets from `j == -1` disagree at the wrap (silent 0.4 freestream drift at NSCBC corners).
- `dns bench` honours `--physics` and reports VRAM THIS process allocates.
- Upstream "ripples" near bodies are 6-12h dispersive standing waves forced by the SUB-CELL BL — not staircase noise, not a start transient. `--cut-flux` ~20% (incomp only), `--penalize` ~15% (HALVES cdf), `--ramp` ~0%. Only cure: resolve the BL (D/√Re ≥ 3 cells). No filters/limiters.
- **Anisotropic cells break isotropy assumptions.** The ghost wall's deep-solid threshold is a DEPTH following the WIDEST local spacing, else drag inverts (`--focal` aspect 1.7: cd 1.49 → −7.6). Audit any `min(hx,hy,hz)` used as "the" cell size before a clustered mesh.
- **`--focal` plateaus are PHYSICAL**: `Focal1D`'s a, b, w are REFERENCE coordinates — build with `Focal1D::fromPhysical`. Containment, guard (3 h_fine), BL warning are physical; `test_focal` pins spacing = h_fine over body + guard. qRef never passes through the map (`sampleCut`, uniform world lattice). Fine cells cost R× their width out of `--n`; adjacent growth > 1.25 rejected.
- **Ghost-wall tally closed by construction** (`gpu_comp_ghost_closure`): a solid cell in any fluid cell's flux stencil (face + edge) is ALWAYS a ghost; with an unusable normal image (overlapping mesh parts) it is imaged from its fluid neighbours — never reset to rest (that opens the tallied surface).
- **Incompressible ghost image reads a CLEAN trilinear cell** (`gpu_tally_couette_torque`, `gpu_ghostfill`): renormalizing over open corners is O(h) off (Couette friction plateaued +6-12%). The image steps out along the normal (1/16 cell, up to a diagonal) until clean; q_ghost = (sdf/d) q(image). Imposed friction is first order (wall curvature); no quadratic image (weights ~7, unbounded ghost). Unresolved spots take a capped fallback (`fallbackCount()`, 0 on resolved convex bodies).
- **Compressible ghost `a` follows the sample it ACTUALLY reads** (`gpu_comp_ghost_couette_exact`): `normalImage`'s renormalized sample sits at sum(w phi)/sum(w), not dsmp; dropped-corner ghosts use that, full stencils keep dw/dsmp bit-for-bit. Any wall-linear profile is exact.
- **Compressible ghost-wall faces are IMPERMEABLE** (`DeviceCompGhost::applyRhs`, `gpu_comp_ghost_imperm`, `plans/verify/impl_imperm.md`). The KG face mean of a cell and its odd image does not zero u_n: the body was a placement-dependent mass source 0.1-1.1% rho U c. Fluid/ghost faces advect nothing relative to the wall: rest — no advection, no pressure work; MRF — none relative to the frame, pressure work p w_n off the SAME corner stream potential; moving — rho u_wall.n {1, u, e} + p u_wall.n, u_wall at the FACE CENTRE (`CompGhostTables::fuwall`). Pressure, viscous and conduction fluxes kept. One thread per fluid cell (CSR from `fcell`), stageAdd/crAt, no atomics; side faces end on the side image's impermeable flux. The tally uses the same override (fc EXACTLY 0 at rest and under MRF). **Anything stepping a `DeviceComp` with a ghost wall puts `applyRhs` in its rhs hook.**
- **`--thin-seal` seals the staircase's leaks, not the body** (`classifyCompGhost` thinSeal, `gpu_thin_seal`, `thin_seal`, `plans/verify/impl_propperf.md`). A fluid/fluid face whose centre segment crosses the body (sphere trace from both ends, midpoint strictly inside; never across the wrap) is an interface face of BOTH fluid cells, each with a side image about its own surface (`addSeal`, the two-sided builder): kernels need no change (`kWallRhs` makes it impermeable, `kSideRhs`/`kSideTally` read each side's image). Mask, ghosts, deep, gfnb unchanged; 0 sealed faces = bit-identical; flag off = byte-identical tables. The sdf must be a distance (lower bound). Not on RANS scalars, the moving-rotor tables or the O-grid (rejected). DTMB P1: CT −33% → +18% vs foam G1 — an overshoot, not parity.
- **Wall pressure image = wall momentum balance `grad p|w = rho (f - a_wall)`** (`gpu_tally_archimedes`, `gpu_tally_kutta_joukowski`, `gpu_rotor_comoving_fixed_point`). Resting, no body force: the zero-gradient copy. Rotor/MRF add centripetal (`p_g = p_s + rho_s a_wall.(x_s - x_g)`, `aspan`; O-grid `wallSpan`); conv plates hydrostatic (`p0 = p1 +- rho1 g hy`). rho, p sampled ON the normal from an all-fluid stencil; adiabatic image keeps T. No two-sample linear p extrapolation (growing wall mode with the central flux). n.div(tau) deliberately omitted (pairs with the tangential term the linear velocity image drops). Imposed test states must SOLVE the solved equations at the wall.
- **A two-sided ghost face reads its own side's image** (`gpu_comp_ghost_twoside`). Under ~2 cells of section a ghost holds ONE image; a face whose ghost normal points away from its fluid cell AND whose fluid normal is > 60° off gets a SIDE image (`ghostImage` along the fluid cell's normal), as rhs correction F(side) - F(shared) (`kSideRhs`, via `applyRhs`) and in every tally span (`kSideTally`). Covers resting, isothermal, moving (rotor tables; capacity covers all bins), MRF, focal, LES/RANS mu_t; NOT RANS scalars (warned). No usable side sample → shared, counted. A THICK body's sharp convex edge stays SHARED (ghost solid 2 cells behind along -n_g AND a deep cell within 3; side-imaging a square's corners made Re 100 cd 9% offset-sensitive). `faceFlux`/`faceFluxCurv` keep their bodies beside `faceFluxOf`/`faceFluxCurvOf` (value form moved NSCBC bits). Don't widen to near-tangent faces (one lens LE face moved Cn ~60 points).
- **SSP-RK3 weights sum to exactly 1 in FP32** (`gpu_mrf_conservation`): `Real(1/3) + Real(2/3)` = 1 + 3e-8. Steppers form `ca = Real(1) - cb` (Sterbenz, cb >= 1/2).
- **`--body cube` is a CUBE** (`dns::sceneCube`, the one definition): rotated-square section (`D` across the DIAGONAL), that tall in z, centred on `cz`, must fit in z; prism at `nz == 1`. `CutGeometry::make(RotatedCube)` has an exact partial-z aperture (bit-identical for a full-span slab). The z-invariant sampling short-cut must exclude cubes. Quasi-2D diamond = `--nz 1`.
- `gpu_runners`: one unquarantined smoke test per runner (exit 0, finite coefficients, healthy projection, stats rows; no literature band). It alone covers `--far tunnel` WITH walls end-to-end.
- Literature-band `val_*` tests are quarantined behind `-DDNS_VALIDATION_BASELINE=ON` by decision. `val_spindown` is the green canary.
- **Re60 cd anchors** (`docs/validation.md` adj. 6): `cyl_re60_n256_cd` 1.818652 (cut-cell, `--far tunnel`), `comp_re60_n256_cd` 1.952196 (ghost-mirror, `--far sponge`). [30, 20 pi] is NOT steady (sheds from t ~ 100, St 0.174). The +7.3% branch gap is NOT compressibility (cd FALLS with Mach; no closure with resolution); cause unisolated (wall AND laterals differ) — the band only pins the branches to each other.
- Blockage excess vs unbounded literature GROWS with Re — bands are repo-calibrated, not raw Williamson. TGV convergence is oscillatory.
- `--pitch`/`--yaw` are DEPRECATED, NOT aircraft angles (raw model axes); bake attitude into the mesh, leave both 0. Viewer needs `camera.up.set(0,0,1)`.
